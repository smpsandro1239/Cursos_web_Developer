Módulo 1: Seletores e Cores

2. Resumo da Aula Anterior

No Módulo 0, preparamos o ambiente e vimos que o CSS serve para dar estilo ao HTML. Descobrimos a sintaxe básica: Seletor + Propriedade + Valor.

3. O Que Vais Aprender Hoje

  • ✅ Seletores de Tag, Classe e ID.
  • ✅ A hierarquia e a Especificidade.
  • ✅ Formatos de cor: Hexadecimal, RGB e Nomes.
  • ✅ Como pintar o fundo e o texto.

4. Teoria: A Hierarquia de Comando

Conceito: No CSS, nem todos os seletores têm o mesmo poder. Se dois seletores tentarem mudar a mesma cor, o mais "específico" ganha. Isso chama-se Especificidade.

🎖️ Analogia: O Exército do Design

Imagina uma hierarquia militar:

  • A Tag (ex: h1): É o Soldado. Comanda toda a gente do seu grupo, mas tem pouco poder individual.
  • A Classe (ex: .destaque): É o Capitão. Comanda um grupo específico de elite e ganha ao soldado.
  • O ID (ex: #titulo-unico): É o General. É único, poderoso e manda em todos os outros.

5. Exemplos Práticos

Exemplo 1: Seletores de Identidade

Diferentes formas de "apontar" para os elementos.

/* Seletor de Tag: Afecta todos os p */
p { color: gray; }

/* Seletor de Classe: Afecta quem tiver class="azul" */
.azul { color: blue; }

/* Seletor de ID: Afecta apenas o id="especial" */
#especial { color: gold; }

Classes usam ponto (.), IDs usam cardinal (#).

Exemplo 2: Formatos de Cor

Como definir cores além das palavras simples.

h1 {
  color: #FF5733;          /* Hexadecimal (RRGGBB) */
  background-color: rgb(255, 87, 51); /* RGB (Red, Green, Blue) */
}

O Hexadecimal é o mais usado por ser curto e fácil de copiar de ferramentas de design.

6. Agora é a Tua Vez!

Cria um ficheiro HTML com três parágrafos:

  1. Dá a classe texto-importante ao primeiro parágrafo.
  2. Dá o id paragrafo-unico ao segundo parágrafo.
  3. No teu CSS, pinta a classe de verde e o ID de laranja.
  4. Pinta a tag p de cinzento. Que cor ficou o primeiro parágrafo? (Spoiler: Verde, porque a classe ganha à tag!).

8. Resumo do Que Aprendemos

  • 📌 Tag é geral, Classe é reutilizável, ID é único.
  • 📌 A ordem de poder é: ID > Classe > Tag.
  • 📌 Hexadecimal (#) e RGB são as formas profissionais de definir cor.
  • 📌 Podes usar várias classes no mesmo elemento separadas por espaços.

9. Desafios Práticos

Desafio 1: O Camaleão

Como aplicas duas classes ao mesmo elemento? (ex: as classes grande e vermelho).

Solução: Separas por espaço no HTML:
<div class="grande vermelho">

Desafio 2: Mistério do Hex

Qual é a cor resultante de #000000 e de #FFFFFF?

Solução: #000000 é Preto (ausência de luz) e #FFFFFF é Branco (máximo de todas as cores).

Desafio 3: A Luta de Poder

Se tiveres body { color: blue; } e p { color: red; }, de que cor será o texto dentro dos parágrafos?

Solução: Vermelho. O seletor p é mais específico para o parágrafo do que o seletor body que é herdado.
