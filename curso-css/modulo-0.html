4. Teoria: A Maquilhagem da Web

Conceito: CSS (Cascading Style Sheets) é a linguagem usada para descrever a apresentação de um documento escrito em HTML. Se o HTML é a estrutura, o CSS é o design.

🎭 Analogia: O Ator no Palco

Imagina uma peça de teatro:

  • O Ator (HTML): É a pessoa que está lá. Sem ele, não há peça.
  • O Figurino e Maquilhagem (CSS): É o que transforma a pessoa num Rei, num Vilão ou num Herói.
  • O Roteiro: As instruções de como o ator deve aparecer (ex: "Entra com uma capa vermelha").

5. Exemplos Práticos

Exemplo 1: Sintaxe Básica

Como "falamos" com o CSS.

/* Seletor { Propriedade: Valor; } */
h1 {
  color: blue;
  font-size: 24px;
}

Aqui estamos a dizer ao browser: "Procura todos os h1 e pinta-os de azul".

Exemplo 2: CSS Externo (O Recomendado)

Ligar o ficheiro CSS no HTML.

<head>
  <link rel="stylesheet" href="style.css">
</head>

Esta é a forma mais limpa, pois separa o conteúdo (HTML) do design (CSS).

Exemplo 3: CSS Inline (Evitar!)

Aplicar estilo diretamente na tag.

<p style="color: red;">Este texto é vermelho.</p>

Embora funcione, torna o código difícil de manter. Usa apenas em casos muito específicos.

6. Agora é a Tua Vez!

Vamos preparar o teu primeiro ficheiro CSS:

  1. Cria uma pasta chamada projeto-css.
  2. Cria um ficheiro index.html com um <h1>.
  3. Cria um ficheiro chamado style.css na mesma pasta.
  4. No CSS, escreve: body { background-color: lightblue; }.
  5. Liga os dois usando a tag <link>.

9. Desafios Práticos

Desafio 1: O Seletor Universal

Como podes aplicar uma fonte específica a TODOS os elementos da página de uma só vez?

Solução: Usando o seletor asterisco (*):
* { font-family: Arial; }

Desafio 2: Ordem de Prioridade

Se tiveres o mesmo estilo no inline e no external, qual é que o browser escolhe?

Solução: O Inline. Tem a maior prioridade por estar "mais perto" do elemento.

Desafio 3: Comentários CSS

Como escreves um comentário no CSS (um texto que o browser ignora)?

Solução: Usando /* comentário */.
