Módulo 0: Preparar o Teu Arsenal

2. Bem-vindo à Jornada!

Antes de começarmos a construir sites incríveis, precisamos de preparar o teu computador. Um guerreiro não vai para a batalha sem as suas armas bem afiadas!

3. O Que Vais Aprender Hoje

Nesta aula de preparação, vamos transformar o teu computador numa verdadeira estação de desenvolvimento:

  • ✅ Instalar o editor de código mais poderoso da atualidade.
  • ✅ Configurar a visualização em tempo real (Live Server).
  • ✅ Aprender segredos de produtividade e atalhos.

4. Teoria: Porquê o VS Code?

O Visual Studio Code (VS Code) é o padrão da indústria. Não é um simples bloco de notas; é uma ferramenta que antecipa o que vais escrever, aponta erros e automatiza tarefas chatas.

O Ecossistema de Desenvolvimento

Para seres um desenvolvedor "Expert", precisas de três coisas:

  1. Editor (O Cérebro): Onde o código nasce (VS Code).
  2. Navegador (O Espelho): Onde vês o resultado (Chrome, Edge ou Firefox).
  3. Live Server (O Motor): Uma ponte que atualiza o Espelho sempre que o Cérebro guarda uma ideia nova.

🎨 Analogia: O Ateliê do Artista

Imagina que és um pintor renascentista:

  • O VS Code é o teu cavalete e paleta de cores inteligente.
  • O HTML é a tela em branco.
  • O Live Server é um assistente mágico que mostra instantaneamente como a pintura ficaria pendurada na galeria final.

5. Exemplos e Dicas de Produtividade

O Atalho "Emmet" (O Teu Melhor Amigo)

Em vez de escreveres 10 linhas de código base, podes escrever apenas isto e carregar em TAB:

!

Este único caractere gera toda a estrutura necessária para começares um projeto.

Atalhos Essenciais

  • 📌 Ctrl + S: Guardar alterações (Faz isto a cada 30 segundos!).
  • 📌 Ctrl + B: Esconder a barra lateral para teres mais espaço.
  • 📌 Alt + Z: Quebrar linhas longas para não teres de fazer scroll horizontal.

6. Preparação Passo a Passo

Segue estes passos para estares pronto para o Módulo 1:

  1. Instalar o Editor: Vai a code.visualstudio.com, descarrega a versão para o teu computador e instala com as opções padrão.
  2. O Motor Real-Time: Abre o VS Code. Clica no ícone de "Extensions" (parecem quadrados) à esquerda. Pesquisa por "Live Server" e clica em Install.
  3. Pasta de Trabalho: Cria uma pasta chamada MeuCursoHTML num local fácil (como o Ambiente de Trabalho). No VS Code, vai a File > Open Folder e escolhe essa pasta.
  4. Primeiro Ficheiro: Clica no ícone de novo ficheiro e cria um chamado teste.html.

💡 Dica: Se vires um botão no canto inferior direito a dizer "Go Live", parabéns! O teu arsenal está pronto.

8. Resumo do Que Aprendemos

  • 📌 O VS Code é a ferramenta padrão para escrever código profissional.
  • 📌 O Live Server permite ver as mudanças em tempo real sem "refresh" manual.
  • 📌 Guardar o trabalho regularmente (Ctrl+S) é o hábito #1 de um programador.
  • 📌 Criar uma pasta organizada é o primeiro passo de qualquer projeto sério.

9. Pequenos Desafios

Desafio 1: O Tema Escuro

Os programadores preferem temas escuros para proteger a visão. Muda o tema do teu VS Code para "Dark Modern" ou "Monokai".

Pressiona Ctrl + K seguido de Ctrl + T para abrir a lista de temas e escolhe um ao teu gosto!
