Aula 12 - Manipulação do DOM

Aprenda a interagir com elementos HTML usando JavaScript.

O que vai ser capaz de fazer?

No final desta aula, você será capaz de:

  • 🎯 Selecionar elementos do DOM com `querySelector`.
  • 🎯 Modificar o conteúdo e estilos de elementos.
  • 🎯 Responder a eventos do utilizador, como cliques.

Teoria (com analogia)

O Document Object Model (DOM)

O DOM é uma representação em árvore da sua página HTML. O JavaScript pode interagir com esta árvore para alterar a estrutura, conteúdo e estilo da página.

💡

Analogia

Pense no DOM como uma árvore genealógica. O `` é o ancestral mais antigo. O `` e o `` são seus filhos. Cada elemento é um membro da família, e o JavaScript pode conversar e dar instruções a qualquer um deles.

Prática (Passo a Passo)

Vamos criar um botão que muda um texto.

Passo 1: Selecione os elementos

Use `document.querySelector` para obter referências ao botão e ao parágrafo.

const meuBotao = document.querySelector('#meuBotao');
const meuParagrafo = document.querySelector('#meuParagrafo');

Passo 2: Adicione um ouvinte de evento

Execute uma função quando o botão for clicado.

meuBotao.addEventListener('click', () => {
    meuParagrafo.textContent = 'O texto foi alterado!';
});

Resumo do que aprendeu

Nesta aula, cobrimos os seguintes pontos-chave:

  • ✅ O DOM é uma representação em árvore do HTML.
  • ✅ `querySelector` é usado para selecionar elementos.
  • ✅ `addEventListener` permite responder a eventos do utilizador.
