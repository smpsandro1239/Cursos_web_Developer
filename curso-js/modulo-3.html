Funções: As Receitas do Código

O que são Funções?

Funções são blocos de código nomeados que executam uma tarefa específica. Em vez de escrever o mesmo código várias vezes, você "empacota-o" numa função e chama-a pelo nome sempre que precisar.

💡

Analogia: Uma Receita de Bolo

Uma função é como uma receita. A declaração da função é o momento em que você escreve a receita (os passos para fazer o bolo). Chamar a função é o ato de seguir a receita para fazer o bolo. Pode usar a mesma receita quantas vezes quiser para fazer vários bolos!

Parâmetros e Return: Ingredientes e o Bolo Pronto

  • Parâmetros: São as informações que você "passa para dentro" da função, como os ingredientes de uma receita.
  • Return: É o valor que a função "devolve" depois de terminar a sua tarefa. É o bolo pronto! Uma função sem return faz uma tarefa, mas não entrega um resultado final.
// Função `somar` com dois parâmetros (ingredientes): a e b
function somar(a, b) {
  const resultado = a + b;
  return resultado; // Devolve o resultado (o bolo pronto)
}

const total = somar(5, 3); // Chama a função com os argumentos 5 e 3
console.log(total); // Mostra 8

Scope: Onde as Variáveis Moram

Escopo (Scope) define onde as variáveis são acessíveis no seu código.

💡

Analogia: A Casa e os Quartos

Pense no seu programa como uma casa. O Escopo Global é a sala de estar – qualquer variável declarada aqui é acessível de qualquer lugar da casa. O Escopo de Função é como um quarto privado. Variáveis declaradas dentro de uma função (num quarto) só são visíveis e acessíveis lá dentro. Ninguém na sala de estar sabe o que se passa dentro do quarto.

const nomeGlobal = "Mundo"; // Escopo Global (na sala)

function saudar() {
  const nomeLocal = "Ana"; // Escopo de Função (no quarto)
  console.log(`Olá, ${nomeLocal}!`); // Funciona, estamos dentro do quarto
  console.log(`Adeus, ${nomeGlobal}.`); // Funciona, a sala é visível do quarto
}

saudar();
// console.log(nomeLocal); // Erro! Não conseguimos ver o que está no quarto a partir da sala.

Exercício: Simulador de Caixa Multibanco

Vamos criar um programa que simula as operações básicas de um multibanco usando funções para organizar o nosso código.

Passo 1: Definir o saldo inicial

Começamos com uma variável para guardar o saldo da conta. Como o saldo vai mudar, usamos let.

let saldo = 1000; // Saldo inicial de 1000€

Passo 2: Criar a função para depositar

Esta função recebe um valor como parâmetro, adiciona-o ao saldo e informa o utilizador.

function depositar(valor) {
  saldo += valor;
  console.log(`Depósito de ${valor}€ efetuado. Saldo atual: ${saldo}€.`);
}

Passo 3: Criar a função para levantar

Esta função verifica se há saldo suficiente. Se houver, subtrai o valor; senão, mostra um erro.

function levantar(valor) {
  if (valor <= saldo) {
    saldo -= valor;
    console.log(`Levantamento de ${valor}€ efetuado. Saldo atual: ${saldo}€.`);
  } else {
    console.log("Saldo insuficiente para este levantamento.");
  }
}

Passo 4: Criar a função para consultar o saldo

Uma função simples que apenas mostra o saldo atual.

function consultarSaldo() {
  console.log(`O seu saldo atual é de ${saldo}€.`);
}

Passo 5: Testar as nossas funções

Agora, vamos chamar as funções para simular as operações.

consultarSaldo(); // Mostra 1000€
depositar(200);     // Mostra "Depósito de 200€... Saldo atual: 1200€."
levantar(300);      // Mostra "Levantamento de 300€... Saldo atual: 900€."
levantar(1000);     // Mostra "Saldo insuficiente..."
consultarSaldo(); // Mostra 900€

Teste o seu conhecimento

1. Uma função foi definida como function calcularIva(preco) { const total = preco * 1.23; }. Se você chamar let resultado = calcularIva(100);, qual será o valor de resultado?

Explicação: A resposta correta é undefined. A função calcula o valor correto, mas nunca o "devolve" para o exterior porque falta a palavra-chave return. Sem um return explícito, uma função devolve sempre undefined.

Resumo do que aprendeu

Nesta aula, aprendeu a organizar e reutilizar o seu código de forma eficiente:

  • ✅ Funções são como "receitas" que guardam um bloco de código para ser reutilizado.
  • ✅ Usamos parâmetros para enviar "ingredientes" para a função e return para receber o "prato final".
  • ✅ O Escopo é como uma casa com quartos: variáveis globais são públicas (na sala), e variáveis de função são privadas (no quarto).
  • ✅ Organizar o código em funções torna-o mais limpo, mais fácil de ler e de manter.
