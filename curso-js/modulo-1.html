Variáveis: As Caixas da Memória

O que são variáveis?

Variáveis são contentores para guardar dados. Cada "caixa" tem uma etiqueta (o nome da variável) e um conteúdo (o valor).

💡

Analogia: Caixas de Arrumação

Pense em variáveis como caixas. Você pode ter uma caixa etiquetada como "Idade" e guardar lá o número 30. Se a idade mudar, você abre a caixa e troca o valor. Simples!

let, const e o velho var

Em JavaScript moderno, usamos principalmente let e const para criar variáveis.

  • let: Cria uma "caixa" cujo conteúdo pode ser alterado. Use-a para valores que vão mudar, como a pontuação num jogo.
  • const: Cria uma "caixa selada". Uma vez que guarda algo nela, não pode mais trocar. Use-a para valores que não devem mudar, como a data de nascimento.
  • var: É a forma antiga de criar variáveis. Evite-a em código novo, pois tem um comportamento que pode causar confusão (chamado hoisting).
// O valor pode ser atualizado
let pontuacao = 100;
pontuacao = 120; // Válido

// O valor não pode ser alterado
const nome = "Ana";
// nome = "Bia"; // Inválido! Causa um erro.

Tipos Primitivos: Os Ingredientes Básicos

JavaScript tem vários "sabores" de dados que podemos guardar nas nossas caixas:

  • String: Texto, sempre entre aspas. Ex: "Olá, mundo!".
  • Number: Números, para cálculos. Ex: 42, 3.14.
  • Boolean: Verdadeiro ou falso (true ou false). Como um interruptor de luz.
  • undefined: Uma caixa vazia, que nunca teve nada lá dentro.
  • null: Uma caixa que foi intencionalmente esvaziada.

Operadores: As Ferramentas

Operadores permitem-nos manipular as nossas variáveis.

  • Aritméticos: + (soma), - (subtração), * (multiplicação), / (divisão).
  • Comparação: === (estritamente igual a), !== (estritamente diferente de), > (maior que), < (menor que). Eles sempre devolvem um boolean.
  • Lógicos: && (E lógico), || (OU lógico). Permitem combinar várias comparações.
💡

Analogia: A Comparação Estrita (===)

Usar === é como comparar duas coisas não só pelo seu valor, mas também pelo seu tipo. O número 5 e o texto "5" parecem iguais, mas não são a mesma coisa. O === é o inspetor rigoroso que diz "não, um é um número, o outro é texto". Use sempre === em vez de == para evitar surpresas!

Exercício: Calculadora de IMC

Vamos criar um programa que calcula o Índice de Massa Corporal (IMC). A fórmula é: peso / (altura * altura).

Passo 1: Perguntar o peso e a altura

Usamos a função prompt() para pedir ao utilizador que insira os dados. O valor que o utilizador escreve é guardado como string.

const pesoString = prompt("Qual é o seu peso em kg?");
const alturaString = prompt("Qual é a sua altura em metros (ex: 1.75)?");

Passo 2: Converter o texto em números

Como o prompt devolve texto, precisamos de converter os valores para number para podermos fazer cálculos. Usamos a função Number().

const peso = Number(pesoString);
const altura = Number(alturaString);

Passo 3: Calcular o IMC

Agora aplicamos a fórmula matemática e guardamos o resultado numa nova variável.

const imc = peso / (altura * altura);

Passo 4: Mostrar o resultado

Usamos console.log() e template literals (texto com `) para mostrar o resultado de forma clara na consola do navegador.

console.log(`O seu IMC é: ${imc.toFixed(2)}`);

O .toFixed(2) serve para arredondar o resultado a duas casas decimais, para ficar mais legível!
