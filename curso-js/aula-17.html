MÓDULO 17

Fetch API

Aprenda a interface moderna do JavaScript para fazer pedidos de rede.

O que vai ser capaz de fazer?

No final desta aula, você será capaz de:

  • 🎯 Fazer um pedido `GET` simples para buscar dados de uma API.
  • 🎯 Lidar com a `Promise` retornada pela `fetch`.
  • 🎯 Enviar dados para um servidor com um pedido `POST`.
  • 🎯 Tratar erros em pedidos de rede.

Teoria (com analogia)

A Conversa com o Mundo Exterior

A Fetch API é uma ferramenta poderosa e flexível que permite ao seu código JavaScript comunicar com servidores através da rede. É a forma padrão de ir buscar (`fetch`) dados a uma API ou enviar informações.

💡

Analogia

Pense na `fetch` como encomendar comida por telefone. Você faz o pedido (`fetch('url')`). O restaurante dá-lhe uma previsão de quando estará pronto (a `Promise`). Quando a comida fica pronta (a `Promise` resolve), eles entregam-lhe uma caixa fechada (o objeto `Response`). Você ainda precisa de abrir a caixa e ver o que está dentro (usando `.json()` ou `.text()`).

Prática (Passo a Passo)

Vamos usar a API pública JSONPlaceholder para praticar.

Passo 1: Fazer um Pedido GET

Vamos buscar um post específico.

fetch('https://jsonplaceholder.typicode.com/posts/1')
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.error('Erro:', error));

Passo 2: Fazer um Pedido POST

Agora, vamos enviar um novo post. Precisamos de configurar o método, os cabeçalhos e o corpo do pedido.

fetch('https://jsonplaceholder.typicode.com/posts', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    title: 'foo',
    body: 'bar',
    userId: 1,
  }),
})
  .then(response => response.json())
  .then(data => console.log('Post criado:', data))
  .catch(error => console.error('Erro:', error));

Teste o seu conhecimento

1. O que o primeiro `.then()` após um `fetch` normalmente faz?

Explicação: A `fetch` retorna uma `Promise` que resolve com um objeto `Response`. Este objeto não é os dados em si, mas sim a resposta HTTP completa. Métodos como `.json()` são chamados para extrair e processar o corpo da resposta.

Resumo do que aprendeu

Nesta aula, aprendeu a usar a Fetch API para:

  • ✅ Fazer pedidos `GET` para buscar recursos.
  • ✅ Lidar com a `Promise` e o objeto `Response`.
  • ✅ Fazer pedidos `POST` para enviar dados, configurando o `method`, `headers` e `body`.

A Fetch API é uma das ferramentas mais importantes no arsenal de um desenvolvedor JavaScript moderno.
