MÓDULO 19

Tratamento de Erros com try/catch

Escreva código mais robusto que sabe como reagir quando as coisas correm mal.

O que vai ser capaz de fazer?

No final desta aula, você será capaz de:

  • 🎯 Entender o que são exceções em programação.
  • 🎯 Usar o bloco `try...catch` para capturar e lidar com erros.
  • 🎯 Lançar os seus próprios erros com a declaração `throw`.
  • 🎯 Usar o bloco `finally` para executar código de limpeza.

Teoria (com analogia)

A Rede de Segurança

Mesmo com o código mais bem escrito, podem ocorrer erros inesperados—uma API pode estar offline, um utilizador pode inserir dados inválidos, etc. O tratamento de erros permite-lhe antecipar esses problemas e fornecer uma resposta controlada, em vez de deixar a sua aplicação "crashar".

💡

Analogia

Pense num trapezista a atuar. O `try` é a performance em si—ele tenta (`try`) fazer a acrobacia. O `catch` é a rede de segurança por baixo. Se o trapezista escorregar (um erro ocorrer), a rede apanha-o (`catch`), e o espetáculo pode continuar (a aplicação não quebra). O `finally` é como o trapezista fazer uma vénia no final, algo que acontece quer a acrobacia tenha sido um sucesso ou não.

Prática (Passo a Passo)

Vamos ver como o `try...catch` funciona na prática.

Passo 1: Capturar um Erro

Vamos tentar aceder a uma variável que não existe. Sem `try...catch`, isto quebraria o script.

try {
  console.log(variavelInexistente);
} catch (error) {
  console.error("Oops, algo correu mal!");
  console.error("Detalhes do erro:", error.message);
}

console.log("O programa continua a correr.");

Passo 2: Lançar um Erro

Podemos criar e lançar os nossos próprios erros.

function dividir(a, b) {
  if (b === 0) {
    throw new Error("Divisão por zero não é permitida.");
  }
  return a / b;
}

try {
  const resultado = dividir(10, 0);
  console.log(resultado);
} catch (error) {
  console.error(error.message);
}

Teste o seu conhecimento

1. Em que bloco de um `try...catch...finally` é colocado o código que pode gerar um erro?

Explicação: O código que se espera que possa lançar uma exceção é colocado dentro do bloco `try`.

Resumo do que aprendeu

Nesta aula, aprendeu a fortalecer o seu código:

  • ✅ O bloco `try` para envolver código potencialmente problemático.
  • ✅ O bloco `catch` para capturar e lidar com os erros.
  • ✅ A declaração `throw` para criar os seus próprios erros.
  • ✅ O bloco `finally` para código que deve ser sempre executado.

Um bom tratamento de erros é a marca de um desenvolvedor profissional.
