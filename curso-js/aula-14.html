JavaScript Modules

Aprenda a organizar o seu código com módulos ES6.

Teoria (com analogia)

O que são JavaScript Modules?

Módulos permitem-lhe dividir o seu código em ficheiros separados e reutilizáveis. Isto torna o código mais organizado, mais fácil de manter e evita a poluição do escopo global.

💡

Analogia

Pense nos módulos como peças de LEGO. Cada peça (módulo) tem uma função específica e pode ser combinada com outras para construir algo maior e mais complexo. Em vez de ter uma única peça gigante e confusa, tem várias peças pequenas e organizadas.

Prática (Passo a Passo)

Vamos criar e usar um módulo. Siga os passos abaixo:

Passo 1: Crie o módulo

Crie um ficheiro `utils.js` e exporte uma função.

// utils.js
export function saudacao(nome) {
  return `Olá, ${nome}!`;
}

Passo 2: Importe o módulo

Crie um ficheiro `main.js` e importe a função do módulo.

// main.js
import { saudacao } from './utils.js';

console.log(saudacao('Mundo'));

Passo 3: Use no HTML

No seu ficheiro HTML, inclua o `main.js` como um módulo.

<script type="module" src="main.js"></script>
