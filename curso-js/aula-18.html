Projeto: To-Do List

Vamos juntar tudo o que aprendeu para criar uma aplicação de lista de tarefas interativa.

O que vai ser capaz de fazer?

No final desta aula, você será capaz de:

  • 🎯 Estruturar uma pequena aplicação web com HTML, CSS e JavaScript.
  • 🎯 Capturar a entrada do utilizador de um campo de texto.
  • 🎯 Adicionar e remover elementos do DOM de forma dinâmica.
  • 🎯 Responder a eventos de clique para marcar tarefas como concluídas.

Teoria (com analogia)

Consolidar Conhecimento

A melhor forma de aprender a programar é construindo coisas. Um projeto de "To-Do List" é um clássico porque o obriga a usar vários conceitos fundamentais de JavaScript em conjunto: manipulação do DOM, eventos e lógica de programação.

💡

Analogia

Construir este projeto é como montar um puzzle. Você já aprendeu o que são as peças de canto (HTML), as peças de borda (CSS) e as peças do meio (JavaScript). Agora, vamos juntar tudo para ver a imagem completa (a sua aplicação funcional).

Prática (Passo a Passo)

Vamos construir a nossa To-Do List.

Passo 1: O HTML

Crie a estrutura com um título, um formulário de entrada e uma lista vazia.

<h1>A Minha Lista de Tarefas</h1>
<input type="text" id="nova-tarefa" placeholder="Adicione uma tarefa">
<button id="adicionar-btn">Adicionar</button>
<ul id="lista-tarefas"></ul>

Passo 2: O JavaScript - Selecionar Elementos

No seu ficheiro JS, comece por obter referências para os elementos HTML.

const inputTarefa = document.getElementById('nova-tarefa');
const btnAdicionar = document.getElementById('adicionar-btn');
const listaTarefas = document.getElementById('lista-tarefas');

Passo 3: Adicionar Tarefas

Crie uma função para adicionar uma nova tarefa à lista quando o botão for clicado.

btnAdicionar.addEventListener('click', () => {
  const textoTarefa = inputTarefa.value;
  if (textoTarefa === '') return;

  const novaLi = document.createElement('li');
  novaLi.textContent = textoTarefa;
  listaTarefas.appendChild(novaLi);

  inputTarefa.value = ''; // Limpa o input
});

Passo 4: Marcar como Concluída

Adicione um evento à lista para que, ao clicar num item, ele seja marcado como concluído.

listaTarefas.addEventListener('click', (event) => {
  if (event.target.tagName === 'LI') {
    event.target.style.textDecoration = 'line-through';
  }
});

Resumo do que aprendeu

Neste projeto, você aplicou os seguintes conceitos:

  • ✅ Seleção de elementos do DOM com `getElementById`.
  • ✅ Leitura do valor de um input com a propriedade `.value`.
  • ✅ Criação dinâmica de elementos com `createElement`.
  • ✅ Adição de elementos ao DOM com `appendChild`.
  • ✅ Gestão de eventos de clique com `addEventListener`.

Parabéns! Você construiu a sua primeira aplicação web interativa.
