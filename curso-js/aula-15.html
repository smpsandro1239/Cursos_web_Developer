MÓDULO 15

Promises e Async/Await

Domine a assincronicidade em JavaScript com as ferramentas mais modernas.

O que vai ser capaz de fazer?

No final desta aula, você será capaz de:

  • 🎯 Entender o que é uma Promise e como ela funciona.
  • 🎯 Consumir Promises usando `.then()` e `.catch()`.
  • 🎯 Escrever código assíncrono mais limpo com `async/await`.

Teoria (com analogia)

Gerir o Tempo em JavaScript

JavaScript é "single-threaded", o que significa que só faz uma coisa de cada vez. Promises são uma forma de lidar com operações que demoram tempo (como um pedido a uma API) sem bloquear o resto do código.

💡

Analogia

Imagine que pede uma pizza. O empregado dá-lhe uma senha (a Promise). Você não fica parado à espera; continua a conversar com os seus amigos. Quando a pizza estiver pronta (a Promise é resolvida), a senha vibra e você vai buscá-la. Se a pizza se queimar (a Promise é rejeitada), a senha avisa-o do problema.

Prática (Passo a Passo)

Vamos usar a `fetch` API, que retorna uma Promise, para buscar dados.

Passo 1: Usando `.then()` e `.catch()`

Este é o método clássico para consumir uma Promise.

fetch('https://jsonplaceholder.typicode.com/todos/1')
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.error('Ocorreu um erro:', error));

Passo 2: Usando `async/await`

Esta é a sintaxe moderna, que torna o código mais legível.

async function buscarDados() {
  try {
    const response = await fetch('https://jsonplaceholder.typicode.com/todos/1');
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error('Ocorreu um erro:', error);
  }
}

buscarDados();

Teste o seu conhecimento

1. O que a palavra-chave `await` faz?

Explicação: `await` só pode ser usado dentro de uma função `async` e serve para pausar a execução e esperar pelo resultado de uma Promise.

Resumo do que aprendeu

Nesta aula, cobrimos as seguintes ferramentas para código assíncrono:

  • ✅ Promises: Objetos que representam a eventual conclusão (ou falha) de uma operação assíncrona.
  • ✅ `.then()` / `.catch()`: Métodos para lidar com o sucesso ou falha de uma Promise.
  • ✅ `async/await`: Sintaxe que permite escrever código assíncrono que se parece com código síncrono, tornando-o mais fácil de ler.

Agora está mais preparado para lidar com a natureza assíncrona da web!
