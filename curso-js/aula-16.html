MÓDULO 16

Local Storage

Descubra como guardar informações no navegador que persistem mesmo depois de a página ser fechada.

O que vai ser capaz de fazer?

No final desta aula, você será capaz de:

  • 🎯 Guardar dados no Local Storage usando `setItem()`.
  • 🎯 Ler dados do Local Storage com `getItem()`.
  • 🎯 Remover dados específicos (`removeItem()`) ou limpar todo o armazenamento (`clear()`).

Teoria (com analogia)

A Memória do Navegador

O Local Storage é um mecanismo que permite que sites e aplicações guardem pares de chave-valor (apenas strings) num navegador web. Os dados não expiram, o que significa que permanecem guardados até serem removidos pelo código ou pelo utilizador.

💡

Analogia

Pense no Local Storage como um pequeno quadro de avisos na sua secretária. Você pode afixar uma nota (ex: `setItem('lembrete', 'Comprar pão')`). Mais tarde, pode ler essa nota (`getItem('lembrete')`). Quando já não precisar dela, pode tirá-la do quadro (`removeItem('lembrete')`). A nota fica lá, mesmo que saia do escritório e volte no dia seguinte.

Prática (Passo a Passo)

Vamos criar uma página que guarda e exibe o nome do utilizador.

Passo 1: Guardar um Item

Abra a consola do seu navegador e execute este código para guardar o nome "Ana".

localStorage.setItem('nomeUtilizador', 'Ana');

Passo 2: Ler o Item

Agora, leia o valor que acabou de guardar. Atualize a página e execute este comando—o valor ainda lá estará!

const nome = localStorage.getItem('nomeUtilizador');
console.log(nome); // Deverá mostrar "Ana"

Passo 3: Guardar Objetos

Como o Local Storage só aceita strings, use `JSON.stringify` para guardar objetos e `JSON.parse` para os ler.

const utilizador = { nome: 'Carlos', idade: 30 };
localStorage.setItem('dadosUtilizador', JSON.stringify(utilizador));

const dadosGuardados = JSON.parse(localStorage.getItem('dadosUtilizador'));
console.log(dadosGuardados.nome); // "Carlos"

Teste o seu conhecimento

1. Que tipo de dados o Local Storage armazena nativamente?

Explicação: O Local Storage armazena todos os dados como strings. Para guardar estruturas mais complexas como objetos, é preciso convertê-los para uma string JSON.

Resumo do que aprendeu

Nesta aula, explorou o Local Storage:

  • ✅ `localStorage.setItem(chave, valor)` para guardar dados.
  • ✅ `localStorage.getItem(chave)` para ler dados.
  • ✅ `localStorage.removeItem(chave)` para remover um item específico.
  • ✅ `JSON.stringify()` e `JSON.parse()` para trabalhar com objetos.

O Local Storage é uma excelente ferramenta para guardar preferências do utilizador, temas, ou outras informações simples.
