Crie os seus próprios elementos HTML encapsulados e reutilizáveis.

Teoria (com analogia)

O que são Web Components?

Web Components são um conjunto de tecnologias que permitem criar elementos HTML personalizados, com o seu próprio comportamento e estilo, que não entram em conflito com o resto da sua página. As tecnologias principais são: Custom Elements, Shadow DOM e HTML Templates.

💡

Analogia

Pense num Web Component como uma peça de LEGO. Cada peça tem uma forma e função específicas, e pode encaixar com outras para construir algo maior. Um Web Component é uma "peça" de interface que pode usar em qualquer projeto, sem se preocupar com os "encaixes" (estilos ou scripts) que estão à sua volta.

Prática (Passo a Passo)

Vamos criar um Web Component para um cartão de utilizador (``).

Passo 1: Crie a classe do componente

Crie uma classe que estende `HTMLElement` e defina o seu construtor.

class UserCard extends HTMLElement {
    constructor() {
        super();
    }
}

Passo 2: Defina o HTML e CSS no Shadow DOM

Dentro do construtor, crie um Shadow DOM e adicione o HTML e o CSS do cartão. Isto mantém os estilos encapsulados.

this.attachShadow({ mode: 'open' });
this.shadowRoot.innerHTML = `
    <style>
        .card { border: 1px solid #ccc; padding: 16px; }
    </style>
    <div class="card">
        <h3>Nome do Utilizador</h3>
    </div>
`;

Passo 3: Registe o Custom Element

Finalmente, diga ao browser que o seu novo elemento existe com `customElements.define()`.

customElements.define('user-card', UserCard);

Agora pode usar `<user-card></user-card>` no seu HTML!
