Programação Funcional em JavaScript

Descubra os princípios da programação funcional e como aplicá-los para escrever um código mais declarativo e previsível.

No final desta aula, você será capaz de:

Teoria (com analogia)

Princípios da Programação Funcional

A programação funcional é um paradigma que trata a computação como a avaliação de funções matemáticas e evita estados e dados mutáveis. Funções puras, por exemplo, sempre produzem o mesmo resultado para os mesmos argumentos e não têm efeitos secundários observáveis.

💡

Analogia

Pense numa função pura como uma máquina de vender automática: você insere uma moeda específica (argumento) e ela entrega sempre o mesmo produto (retorno), sem alterar nada à sua volta. Funções impuras seriam como cozinhar: o resultado pode variar dependendo da temperatura do fogão (estado externo) e o processo suja a cozinha (efeito secundário).

Prática (Passo a Passo)

Vamos usar `map`, `filter` e `reduce` para processar uma lista de números.

Passo 1: Utilizar `map` para duplicar os números

O método `map` cria um novo array com os resultados de uma função aplicada a cada elemento.

const numeros = [1, 2, 3, 4, 5];
const duplicados = numeros.map(n => n * 2);
// resultado: [2, 4, 6, 8, 10]

Passo 2: Utilizar `filter` para obter apenas os números pares

O método `filter` cria um novo array com todos os elementos que passam num teste.

const pares = numeros.filter(n => n % 2 === 0);
// resultado: [2, 4]

Passo 3: Utilizar `reduce` para somar todos os números

O método `reduce` aplica uma função a um acumulador e a cada elemento do array para o reduzir a um único valor.

const soma = numeros.reduce((acumulador, n) => acumulador + n, 0);
// resultado: 15
