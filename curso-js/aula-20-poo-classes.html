POO e Classes

Estruture o seu código de forma mais organizada e reutilizável com o paradigma da Programação Orientada a Objetos.

O que vai ser capaz de fazer?

No final desta aula, você será capaz de:

  • 🎯 Entender os conceitos básicos da Programação Orientada a Objetos (POO).
  • 🎯 Definir uma `class` com um `constructor` e métodos.
  • 🎯 Criar instâncias (objetos) a partir de uma classe.
  • 🎯 Implementar herança entre classes com `extends` e `super`.

Teoria (com analogia)

Modelar o Mundo Real

A Programação Orientada a Objetos é um paradigma que nos permite estruturar o nosso software de uma forma que espelha o mundo real, através da criação de "objetos" que têm as suas próprias propriedades e comportamentos. As classes são os "moldes" para criar esses objetos.

💡

Analogia

Pense numa planta de uma casa (`class`). A planta define a estrutura: quantos quartos, qual a área, etc. A partir dessa única planta, você pode construir várias casas reais (as instâncias ou objetos). Cada casa terá as mesmas características base, mas pode ter diferentes cores de parede ou mobília (as propriedades de cada instância).

Prática (Passo a Passo)

Vamos criar uma classe `Carro`.

Passo 1: Defina a Classe

Crie uma classe `Carro` com um `constructor` para definir a marca e o modelo, e um método para exibir a informação.

class Carro {
  constructor(marca, modelo) {
    this.marca = marca;
    this.modelo = modelo;
  }

  mostrarInfo() {
    return `${this.marca} ${this.modelo}`;
  }
}

Passo 2: Crie Instâncias

Crie dois objetos `Carro` diferentes.

const meuCarro = new Carro('Tesla', 'Model S');
const outroCarro = new Carro('Ford', 'Mustang');

console.log(meuCarro.mostrarInfo()); // "Tesla Model S"
console.log(outroCarro.mostrarInfo()); // "Ford Mustang"

Passo 3: Crie uma Subclasse (Herança)

Vamos criar uma classe `CarroEletrico` que herda de `Carro` e adiciona uma propriedade de autonomia.

class CarroEletrico extends Carro {
  constructor(marca, modelo, autonomia) {
    super(marca, modelo); // Chama o construtor da classe pai
    this.autonomia = autonomia;
  }
}

const meuTesla = new CarroEletrico('Tesla', 'Model 3', 500);
console.log(meuTesla.mostrarInfo()); // "Tesla Model 3"
console.log(meuTesla.autonomia); // 500

Teste o seu conhecimento

1. Qual palavra-chave é usada para criar uma classe que herda de outra?

Explicação: A palavra-chave `extends` é usada para criar uma subclasse (ou classe filha) que herda as propriedades e métodos de uma superclasse (ou classe pai).

Resumo do que aprendeu

Nesta aula, demos os primeiros passos em POO com JavaScript:

  • ✅ `class`: O molde para criar objetos.
  • ✅ `constructor`: O método especial para criar e inicializar um objeto.
  • ✅ `new`: A palavra-chave para criar uma instância de uma classe.
  • ✅ `extends`: Para criar uma nova classe baseada noutra.
  • ✅ `super`: Para chamar o construtor da classe pai.

A POO é um pilar do desenvolvimento de software moderno e ajudá-lo-á a escrever código mais limpo e escalável.
