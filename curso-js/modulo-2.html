MÓDULO 2

CONTROLO DE FLUXO

Ensinar o nosso programa a pensar e a repetir tarefas.

O que vai ser capaz de fazer?

No final desta aula, você será capaz de:

  • 🎯 Criar programas que tomam decisões com base em condições (if/else).
  • 🎯 Automatizar tarefas repetitivas usando loops (for e while).
  • 🎯 Controlar a execução de um loop com break e continue.
  • 🎯 Construir um jogo interativo que responde às ações do utilizador.

Tomar Decisões e Repetir Ações

Condicionais: As Bifurcações no Código

Condicionais permitem que o seu programa execute blocos de código diferentes com base numa condição ser true ou false.

💡

Analogia: O GPS Inteligente

Pense no if/else como um GPS. Se (if) a estrada principal estiver livre, siga em frente. Senão, se (else if) houver trânsito moderado, sugira uma rota alternativa. Senão (else), se tudo o resto falhar, recalcule para a rota mais curta. O programa escolhe o caminho certo com base nas condições do "trânsito" (os seus dados).

let idade = 20;

if (idade >= 18) {
  console.log("Pode entrar na festa."); // Este código executa
} else {
  console.log("Não tem idade suficiente.");
}

Loops: O Piloto Automático

Loops são usados para executar o mesmo bloco de código várias vezes, até que uma condição de paragem seja atingida.

O loop for

Ideal para quando você sabe exatamente quantas vezes quer repetir uma ação.

💡

Analogia: Fazer 10 flexões

Um loop for é como uma série de exercícios. Você tem: 1) um ponto de partida (começar na flexão 1), 2) uma condição para continuar (enquanto não chegar a 10), e 3) um incremento (fazer a próxima). É perfeito para repetições contadas.

// Contar de 1 a 5
for (let i = 1; i <= 5; i++) {
  console.log(`Contagem: ${i}`);
}

O loop while

Perfeito para quando você não sabe quantas vezes precisa de repetir, apenas que deve continuar enquanto uma condição for verdadeira.

💡

Analogia: Encher um balde

Um loop while é como encher um balde de água. Você não conta as gotas. Você simplesmente continua a encher enquanto (while) o balde não estiver cheio. A repetição para quando a condição ("balde não está cheio") se torna falsa.

let bateria = 10;

while (bateria > 0) {
  console.log(`Bateria restante: ${bateria}%`);
  bateria--; // Descarrega a bateria
}
console.log("Bateria descarregada!");

Exercício: Jogo "Adivinha o Número"

Vamos construir um jogo onde o computador pensa num número de 1 a 100 e o utilizador tem de adivinhar qual é.

Passo 1: Gerar o número secreto

Usamos Math.random() para gerar um número aleatório entre 0 e 1, multiplicamos por 100, e Math.floor() para arredondar para baixo. Somamos 1 para garantir que o número está entre 1 e 100.

const numeroSecreto = Math.floor(Math.random() * 100) + 1;
let tentativa;

Passo 2: Criar um loop para as tentativas

Usaremos um loop while que continua enquanto a tentativa do utilizador for diferente do número secreto.

while (tentativa !== numeroSecreto) {
  // O código do jogo vai aqui dentro
}

Passo 3: Pedir a tentativa e converter para número

Dentro do loop, pedimos ao utilizador para adivinhar e convertemos a resposta para um número.

  const resposta = prompt("Adivinhe o número (entre 1 e 100):");
  tentativa = Number(resposta);

Passo 4: Dar pistas com if/else

Comparamos a tentativa com o número secreto e damos uma pista ao utilizador.

  if (tentativa < numeroSecreto) {
    alert("Muito baixo! Tente um número maior.");
  } else if (tentativa > numeroSecreto) {
    alert("Muito alto! Tente um número menor.");
  }

Passo 5: Celebrar a vitória e terminar o jogo

Quando o utilizador acerta, o loop while termina. Depois do loop, exibimos uma mensagem de parabéns.

alert(`Parabéns! Você acertou! O número era ${numeroSecreto}.`);

Teste o seu conhecimento

1. Se você precisa de executar uma ação para cada um dos 7 dias da semana, qual loop é o mais indicado e porquê?

Explicação: A resposta correta é o loop for. Ele é ideal para situações onde o número de iterações é conhecido à partida, como neste caso (7 dias).

Resumo do que aprendeu

Nesta aula, aprendeu a dar "inteligência" aos seus programas:

  • ✅ Usamos if/else para tomar decisões, como um GPS que escolhe o melhor caminho.
  • ✅ Usamos for para repetir tarefas um número específico de vezes (fazer flexões).
  • ✅ Usamos while para repetir tarefas até que uma condição mude (encher um balde).
  • ✅ Combinámos estes conceitos para criar um jogo completo, o que mostra o poder do controlo de fluxo!
