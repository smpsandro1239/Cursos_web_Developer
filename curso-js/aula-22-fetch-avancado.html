Fetch API: Pedidos POST e Erros

Vá além do GET e aprenda a enviar dados e a gerir respostas de erro.

O que vai ser capaz de fazer?

No final desta aula, você será capaz de:

  • 🎯 Enviar dados para um servidor usando um pedido `POST`.
  • 🎯 Configurar cabeçalhos (`headers`) num pedido `fetch`.
  • 🎯 Verificar se a resposta de um pedido foi bem-sucedida (`response.ok`).

Teoria (com analogia)

Enviando Encomendas para a API

Até agora, usamos o `fetch` para pedir dados (GET). Mas e se quisermos enviar dados para criar ou atualizar um recurso? Para isso, usamos o método `POST`. Num pedido `POST`, enviamos um "corpo" (`body`) com os dados, geralmente em formato JSON, e definimos os `headers` para informar o servidor do tipo de conteúdo que estamos a enviar.

💡

Analogia

Um pedido `GET` é como pedir uma ementa num restaurante. Um pedido `POST` é como fazer o pedido da sua comida. Você entrega uma nota ao empregado (o `body`) com o que quer, e especifica que a nota está escrita em português (o `header` `'Content-Type': 'application/json'`). Se o pedido for bem recebido pela cozinha, o empregado dá-lhe um "ok" (a propriedade `response.ok`).

Prática (Passo a Passo)

Vamos usar o `fetch` para criar um novo "post" num serviço de API falso (JSONPlaceholder).

Passo 1: Prepare os dados e as opções

Crie um objeto com os dados que quer enviar e um objeto de configuração para o `fetch`.

const newPost = {
    title: 'foo',
    body: 'bar',
    userId: 1,
};

const fetchOptions = {
    method: 'POST',
    body: JSON.stringify(newPost),
    headers: {
        'Content-type': 'application/json; charset=UTF-8',
    },
};

Passo 2: Faça o pedido `fetch`

Chame o `fetch` com o URL e as opções. Use `async/await` para um código mais limpo.

async function createPost() {
    const response = await fetch('https://jsonplaceholder.typicode.com/posts', fetchOptions);

    if (!response.ok) {
        console.error(`Erro: ${response.status}`);
        return;
    }

    const data = await response.json();
    console.log(data);
}

createPost();

Resumo do que aprendeu

Nesta aula, aprofundou os seus conhecimentos sobre a Fetch API:

  • ✅ Como fazer pedidos `POST` para enviar dados.
  • ✅ A importância de configurar o `method`, `body` e `headers`.
  • ✅ Como verificar a propriedade `response.ok` para um tratamento de erros robusto.
