MÓDULO 13

DOM Manipulation

Aprenda a interagir e modificar o conteúdo de uma página web com JavaScript.

O que vai ser capaz de fazer?

No final desta aula, você será capaz de:

  • 🎯 Selecionar elementos do DOM usando querySelector e getElementById.
  • 🎯 Modificar o conteúdo e os estilos de elementos.
  • 🎯 Criar e adicionar novos elementos à página.
  • 🎯 Responder a eventos do utilizador, como cliques.

Teoria (com analogia)

O que é o DOM?

O DOM (Document Object Model) é uma representação em árvore da estrutura de uma página HTML. O JavaScript pode interagir com o DOM para alterar a estrutura, o conteúdo e o estilo da página em tempo real, sem precisar de recarregar a página.

💡

Analogia

Pense na sua página HTML como uma árvore de Natal. O DOM é a árvore montada. Com o JavaScript, você pode ser o decorador que adiciona novas bolas (elementos), muda a cor das luzes (estilos) ou troca a estrela no topo (conteúdo).

Prática (Passo a Passo)

Vamos criar uma página interativa:

Passo 1: Selecione um Elemento

Use querySelector para selecionar o primeiro parágrafo da sua página.

const paragrafo = document.querySelector('p');

Passo 2: Mude o Conteúdo

Altere o texto do parágrafo selecionado.

paragrafo.textContent = 'Este texto foi alterado com JavaScript!';

Passo 3: Crie um Novo Elemento

Crie um novo botão e adicione-o ao corpo da página.

const novoBotao = document.createElement('button');
novoBotao.textContent = 'Clique Aqui';
document.body.appendChild(novoBotao);

Passo 4: Adicione um Event Listener

Faça com que algo aconteça quando o botão for clicado.

novoBotao.addEventListener('click', () => {
    alert('O botão foi clicado!');
});
