ESTRUTURAS DE DADOS

Como organizar e agrupar os seus dados de forma inteligente.

No final desta aula, você será capaz de:

Arrays e Objetos: Os Arquivos do Código

Arrays: O Comboio de Dados

Um Array é uma lista ordenada de valores. É perfeito para guardar uma coleção de itens do mesmo tipo, como uma lista de nomes ou de números.

💡

Analogia: Um Comboio

Pense num Array como um comboio. Cada valor é um passageiro numa vagão. O mais importante é que cada vagão é numerado, a começar pelo vagão 0. Para encontrar um passageiro, basta saber o número do seu vagão (o seu índice).

// Um array de nomes
const nomes = ["Ana", "Bruno", "Carlos"];

// Aceder ao passageiro no vagão 0
console.log(nomes[0]); // Mostra "Ana"

// Adicionar um novo passageiro ao fim do comboio
nomes.push("Diana");
console.log(nomes); // Mostra ["Ana", "Bruno", "Carlos", "Diana"]

Objetos: O Armário Etiquetado

Um Objeto é uma coleção de pares chave-valor. É ideal para descrever uma única "coisa" com várias propriedades.

💡

Analogia: Um Armário com Gavetas

Pense num Objeto como um armário. O armário representa uma única entidade (ex: uma pessoa). Cada gaveta tem uma etiqueta (a "chave" ou "propriedade", como "nome" ou "idade") e um conteúdo (o "valor"). Para encontrar uma informação, você não usa um número, mas sim o nome da etiqueta na gaveta.

// Um objeto que descreve um utilizador
const utilizador = {
  nome: "Sandro",
  idade: 30,
  isAdmin: true
};

// Aceder ao conteúdo da gaveta "nome"
console.log(utilizador.nome); // Mostra "Sandro"

// Adicionar uma nova gaveta "cidade"
utilizador.cidade = "Lisboa";
console.log(utilizador.cidade); // Mostra "Lisboa"

Exercício: Carrinho de Compras

Vamos criar um sistema simples para um carrinho de compras online, usando arrays e objetos.

Passo 1: Criar os produtos

Vamos criar um array chamado carrinho. Cada item no carrinho será um objeto com as propriedades nome e preco.

const carrinho = [
  { nome: "Maçã", preco: 0.5 },
  { nome: "Pão", preco: 1.2 },
  { nome: "Leite", preco: 0.9 }
];

Passo 2: Adicionar um novo produto

Vamos adicionar um novo produto ao nosso carrinho usando o método .push().

function adicionarProduto(nome, preco) {
  carrinho.push({ nome: nome, preco: preco });
  console.log(`"${nome}" foi adicionado ao carrinho.`);
}

adicionarProduto("Queijo", 2.5);

Passo 3: Calcular o total

Vamos criar uma função que percorre o array carrinho e soma o preço de todos os produtos. Usaremos um loop for...of para isto.

function calcularTotal() {
  let total = 0;
  for (const produto of carrinho) {
    total += produto.preco; // Adiciona o preço do produto ao total
  }
  return total;
}

const totalAPagar = calcularTotal();
console.log(`Total do carrinho: ${totalAPagar.toFixed(2)}€`);

Passo 4: Aplicar um desconto

Agora, uma função que recebe o total e uma percentagem de desconto, e devolve o novo total.

function aplicarDesconto(total, percentagem) {
  const desconto = total * (percentagem / 100);
  const totalComDesconto = total - desconto;
  return totalComDesconto;
}

const totalFinal = aplicarDesconto(totalAPagar, 10); // Aplicar 10% de desconto
console.log(`Total com 10% de desconto: ${totalFinal.toFixed(2)}€`);

Teste o seu conhecimento

1. Você quer guardar os detalhes de um filme: título, ano de lançamento e realizador. Qual estrutura de dados é mais adequada?

Explicação: A resposta correta é um Objeto. Um objeto é perfeito para agrupar propriedades relacionadas que descrevem uma única entidade, como um filme. As chaves (título, ano) tornam o código muito mais legível do que um array com índices numéricos (filme[0], filme[1]).

Resumo do que aprendeu

Nesta aula, descobriu como organizar os seus dados de forma estruturada:

  • ✅ Arrays são como comboios, ideais para listas ordenadas de itens, acedidos por um índice numérico (meuArray[0]).
  • ✅ Objetos são como armários etiquetados, perfeitos para descrever uma entidade com as suas propriedades, acedidas por chaves (meuObjeto.nome).
  • ✅ Aprendemos a manipular estas estruturas, adicionando e acedendo a dados.
  • ✅ Usámos um loop para processar uma lista de objetos, uma das tarefas mais comuns em programação!

Com o domínio das estruturas de dados, você está pronto para mergulhar num dos paradigmas mais poderosos da programação: a Programação Orientada a Objetos.
