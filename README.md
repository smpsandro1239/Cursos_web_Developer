## Sobre o Projeto

O **Aprende Web** é uma plataforma de aprendizagem web gratuita e de código aberto, desenvolvida inteiramente em HTML5, CSS3 e JavaScript puro (Vanilla). A plataforma oferece 4 cursos completos, com um total de **84 módulos** de conteúdo, quizzes interativos, sistema de gamificação e certificados digitais.

### O que torna este projeto único?

- **100% gratuito** — sem subscrições, sem paywalls, sem limitações
- **Aprendizagem prática** — cada módulo inclui exemplos de código, desafios e playground interativo
- **Gamificação** — conquistas, streaks diários e leaderboard para manter a motivação
- **PWA** — funciona offline e pode ser instalado como aplicação nativa
- **Acessível** — otimizado para leitores de ecrã e navegação por teclado
- **Responsivo** — funciona em computadores, tablets e telemóveis

## Funcionalidades da Plataforma

### Sistema de Aprendizagem
- **Quizzes interativos** — 5+ perguntas por módulo com feedback imediato e explicações detalhadas
- **Desafios práticos** — 5+ desafios por módulo com soluções reveláveis
- **Code Playground** — editor HTML/CSS/JS com pré-visualização em tempo real
- **Exemplos de código** — 3+ exemplos por módulo com syntax highlighting
- **Analogias** — cada conceito técnico é explicado com uma analogia simples
- **Resumo da aula anterior** — continuidade entre módulos

### Gamificação
- **20 conquistas (badges)** — desbloqueadas ao completar módulos e quizzes
- **Streak diário** — sequência de dias de estudo consecutivos
- **Leaderboard** — ranking global dos melhores alunos
- **Certificados digitais** — gerados automaticamente ao completar um curso (formato PNG)

### Interface e Experiência
- **Dark Mode** — tema escuro com toggle automático
- **Design responsivo** — adaptado a computadores, tablets e telemóveis
- **Navegação intuitiva** — menu, breadcrumbs e botões anterior/próximo
- **PWA (Progressive Web App)** — instalação nativa e funcionamento offline
- **Acessibilidade** — ARIA labels, navegação por teclado, contraste adequado
- **SEO otimizado** — sitemap.xml, robots.txt, meta tags Open Graph

### Dashboards
Cada curso tem um dashboard dedicado com:
- Progresso visual (barra de progresso)
- Lista de módulos concluídos
- Pontuação dos quizzes
- Tempo de estudo
- Certificado disponível ao completar 100%

## Instalação Local

### Pré-requisitos
- Um navegador web moderno (Chrome, Firefox, Edge)
- Um servidor local (recomendado: VS Code com extensão Live Server)

### Passos

1. **Clonar o repositório**
```bash
git clone https://github.com/smpsandro1239/Cursos_web_Developer.git
```

2. **Abrir no VS Code**
```bash
cd Cursos_web_Developer/Cursos_web_Developer
code .
```

3. **Iniciar o servidor local**
   - Instala a extensão **Live Server** no VS Code
   - Clica com o botão direito em `index.html`
   - Seleciona **"Open with Live Server"**

4. **Aceder à plataforma**
   - Abre `http://127.0.0.1:5500` no navegador

### Alternativa sem VS Code
```bash
cd Cursos_web_Developer/Cursos_web_Developer
python -m http.server 8080
# Abrir http://localhost:8080
```
