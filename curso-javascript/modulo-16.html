Módulo 16: ES6+ Master (O Novo JS)

2. Resumo da Aula Anterior

No Módulo 15, aprendemos a usar Async/Await e Fetch para trazer dados da internet. Hoje, vamos aprender as ferramentas de escrita ultra-rápida que os profissionais usam todos os dias: o JavaScript Moderno (ES6+).

3. O Que Vais Aprender Hoje

  • ✅ Arrow Functions (mais curtas e limpas).
  • ✅ Template Literals (strings com superpoderes).
  • ✅ Desestruturação de Objetos e Arrays.
  • ✅ Operadores Spread e Rest (...).

4. Teoria: Evolução e Atalhos

Conceito: O JavaScript evoluiu muito desde 2015 (ES6). As novas ferramentas não mudam o que o código faz, mas sim **como o escrevemos**, tornando-o mais legível, menos repetitivo e mais elegante.

✍️ Analogia: Do Diário à Mensagem de Texto

Imagina que estás a escrever uma mensagem:

  • JS Antigo (O Diário): Escrevias cartas formais: "Excelentíssimo Senhor Sandro, venho por este meio informar que..." (Muito código para pouca ação).
  • JS Moderno (WhatsApp): Usas abreviaturas, emojis e atalhos: "Hey Sandro! Tudo ok? 👍" (Vai direto ao ponto, é mais rápido e toda a gente percebe).

O ES6+ é o "WhatsApp" do JavaScript: foca-se na eficiência.

5. Exemplos Práticos

Exemplo 1: Arrow Functions e Templates

Menos `function`, menos `+` e mais ` => `.

// Antigo
function saudar(nome) { return "Olá " + nome; }

// Moderno ✅
const saudar = (nome) => `Olá ${nome}! Bem-vindo.`;

console.log(saudar("Sandro"));

Exemplo 2: Desestruturação

Extrair dados sem repetir o nome do objeto mil vezes.

const user = { nome: "Sandro", idade: 30, pais: "Portugal" };

// Atalho Moderno ✅
const { nome, idade } = user;

console.log(nome); // "Sandro"
console.log(idade); // 30

Exemplo 3: Operador Spread (...)

"Espalhar" ou copiar dados rapidamente.

const frutas = ["Maçã", "Banana"];
const todasFrutas = [...frutas, "Laranja", "Pêra"];

console.log(todasFrutas); // ["Maçã", "Banana", "Laranja", "Pêra"]

const configPadrao = { tema: "dark" };
const configUser = { ...configPadrao, cor: "blue" };

9. Desafios Práticos

Desafio 1: A Troca de Valores

Como trocarias os valores de duas variáveis (A e B) sem usar uma terceira variável temporária, usando apenas desestruturação de Array?

Solução:
[a, b] = [b, a]; (O JavaScript resolve a lista da direita primeiro e depois atribui à esquerda).

Desafio 2: O Resto da Lista

Se tiveres const [primeiro, ...resto] = [10, 20, 30, 40];, o que estará guardado na variável resto?

Solução: Estará o Array [20, 30, 40]. Aqui o operador chama-se **Rest** porque guarda o "resto" dos elementos.

Desafio 3: Clonagem Segura

Porque é que usamos const novo = [...antigo] em vez de const novo = antigo quando queremos copiar um Array?

Solução: Porque os Arrays são referências. Se fizeres novo = antigo, ao mudares um, mudas o outro. Com o Spread, crias uma **cópia real** independente.
