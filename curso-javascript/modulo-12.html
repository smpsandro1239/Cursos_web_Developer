2. Resumo da Aula Anterior

No Módulo 11, aprendemos a reagir a cliques e teclas. Hoje, vamos focar-nos na parte mais importante de qualquer site: a captura de dados através de Formulários e como impedir que a página recarregue sozinha.

3. O Que Vais Aprender Hoje

  • ✅ O evento submit.
  • ✅ O superpoder do event.preventDefault().
  • ✅ Capturar valores de Inputs e Textareas.
  • ✅ Validação básica de campos via JavaScript.

4. Teoria: Controlar o Fluxo

Conceito: Por defeito, quando clicas num botão de "Enviar" num formulário, o browser tenta enviar os dados para um servidor e recarrega a página. No JavaScript moderno, nós queremos "travar" esse comportamento para processar os dados nós mesmos.

🛑 Analogia: O Semáforo

Imagina que o teu formulário é um carro a aproximar-se de um cruzamento:

  • Comportamento Padrão: O carro passa direto e vai para outra rua (a página recarrega).
  • event.preventDefault(): É como meteres um sinal de **STOP** vermelho. Tu obrigas o carro a parar para que possas revistar o que está lá dentro (os dados) antes de o deixares ir (ou não).

Sem este comando, o teu código JavaScript "morre" assim que a página faz refresh.

5. Exemplos Práticos

Exemplo 1: Capturar o Submit

O ritual sagrado do formulário.

const formulario = document.querySelector("#meu-form");

formulario.addEventListener("submit", function(event) {
  // ⛔ Parar o refresh da página!
  event.preventDefault();

  console.log("Formulário capturado com sucesso!");
});

Exemplo 2: Ler os Dados

Usar a propriedade `.value`.

const inputNome = document.querySelector("#nome");

formulario.addEventListener("submit", (e) => {
  e.preventDefault();

  const nomeUtilizador = inputNome.value;
  alert("Olá, " + nomeUtilizador);
});

Exemplo 3: Validação Simples

Impedir o envio se algo estiver errado.

formulario.addEventListener("submit", (e) => {
  e.preventDefault();

  if (inputNome.value === "") {
    alert("Por favor, escreve o teu nome!");
    return; // Para aqui e não faz mais nada
  }

  console.log("Enviando dados...");
});

8. Resumo do Que Aprendemos

  • 📌 O evento **submit** dispara no formulário, não no botão.
  • 📌 **preventDefault()** evita que o browser recarregue a página.
  • 📌 Usamos **.value** para extrair o que o utilizador escreveu.
  • 📌 Podemos usar a lógica de IF para validar os campos antes de os aceitar.

9. Desafios Práticos

Desafio 1: O Verificador de Password

Cria um formulário com duas caixas de password. Ao submeter, verifica se elas são iguais. Se não forem, mostra uma mensagem de erro em vermelho.

Solução:
if (pass1.value !== pass2.value) { msg.style.color = 'red'; msg.textContent = 'Passwords diferentes!'; }

Desafio 2: Limpeza Automática

Após o utilizador submeter o formulário com sucesso (e depois do preventDefault), como podes limpar a caixa de texto para que ela fique vazia novamente?

Solução:
input.value = ""; ou formulario.reset();

Desafio 3: Checkbox Check

Imagina que tens uma checkbox de "Aceito os termos". Como verificas se ela está marcada (checked) no JavaScript?

Solução: Usando a propriedade .checked. Ex: if (checkbox.checked) { ... }. Devolve true ou false.
