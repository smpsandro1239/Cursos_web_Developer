Módulo 15: Async/Await e APIs (Fetch)

2. Resumo da Aula Anterior

No Módulo 14, descobrimos as Promises e como usar o .then() e .catch(). Hoje, vamos aprender a forma mais moderna e elegante de escrever esse código e como ligar o nosso site a dados reais do mundo exterior.

3. O Que Vais Aprender Hoje

  • ✅ Sintaxe Async e Await.
  • ✅ Como consumir APIs com Fetch.
  • ✅ Tratar erros com try / catch.
  • ✅ Transformar respostas em JSON.

4. Teoria: Conversar com a Internet

Conceito: `Async/Await` é uma "roupa" mais bonita para as Promises. Permite escrever código assíncrono que parece síncrono (lido de cima para baixo). Já o `Fetch` é a ferramenta que o browser nos dá para ir buscar informações a outros sites (APIs).

📞 Analogia: O Intercomunicador Inteligente

Imagina que estás a trabalhar num escritório:

  • Modo .then() (Antigo): Tu mandas um email ao arquivista e dizes "Quando tiveres o documento, avisa-me aqui (no email)". Tu voltas ao trabalho e esperas o sinal.
  • Modo Async/Await (Moderno): Tu falas pelo intercomunicador: "Await (Espera) aí um momento enquanto eu busco o ficheiro". O tempo para para ti naquela tarefa específica, mas o resto do escritório continua a funcionar. O código fica muito mais limpo de ler!

5. Exemplos Práticos

Exemplo 1: De Promise para Async/Await

A evolução da sintaxe.

async function pegarDados() {
  console.log("Aguardando...");

  // O 'await' faz o código esperar aqui sem travar o site
  const resultado = await minhaPromessa;

  console.log(resultado);
}

pegarDados();

Exemplo 2: O Poder do FETCH

Ir buscar dados reais (ex: lista de utilizadores).

async function carregarUtilizadores() {
  const resposta = await fetch("https://jsonplaceholder.typicode.com/users");
  const dados = await resposta.json(); // Converte para objeto JS

  console.log(dados[0].name); // Imprime o nome do 1º user
}

carregarUtilizadores();

Exemplo 3: Tratamento com Try/Catch

O substituto do .catch() no modo async.

async function buscarClima() {
  try {
    const res = await fetch("url-errada-api");
    const data = await res.json();
  } catch (erro) {
    console.error("Infelizmente algo falhou: ", erro);
  }
}

O bloco `try` tenta executar o código; se houver qualquer erro, ele "salta" imediatamente para o `catch`.

8. Resumo do Que Aprendemos

  • 📌 **Async** marca uma função como assíncrona.
  • 📌 **Await** pausa a execução DAQUELA função até a Promise ser resolvida.
  • 📌 **Fetch** é a forma padrão de trazer dados externos para o seu site.
  • 📌 O par **Try/Catch** é essencial para lidar com falhas de rede de forma graciosa.

9. Desafios Práticos

Desafio 1: O Perigo do Esquecimento

O que acontece se usares a palavra await dentro de uma função que NÃO tem a palavra async no início?

Solução: O JavaScript dará um erro de Sintaxe (Syntax Error). O await só pode ser usado dentro de funções async.

Desafio 2: Perfil do GitHub

Usa o fetch para ir buscar os teus dados ao GitHub (ou de um user famoso): https://api.github.com/users/nome-do-user. Como mostrarias a foto de perfil (`avatar_url`) dele no ecrã?

Solução:
const user = await res.json(); img.src = user.avatar_url;

Desafio 3: Lista de Posts

Tenta fazer o fetch de https://jsonplaceholder.typicode.com/posts e usa um loop for ou forEach para criar um <h2> para cada título de post recebido.

Solução:
posts.forEach(p => { const h2 = document.createElement('h2'); h2.textContent = p.title; document.body.appendChild(h2); });
