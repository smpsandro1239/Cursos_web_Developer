No Módulo 7, aprendemos a usar Objetos para organizar dados complexos. Hoje, vamos aprender a organizar **ações**. Em vez de escreveres o mesmo código 10 vezes, vais criar uma "receita" e chamá-la sempre que precisares.

  • ✅ Como declarar uma função com function.
  • ✅ Como "chamar" ou executar o código.
  • ✅ O Princípio DRY (Don't Repeat Yourself).

4. Teoria: A Fábrica de Código

Conceito: Uma função é um bloco de código desenhado para executar uma tarefa específica. Podes pensar nela como um pequeno programa dentro do teu programa principal.

☕ Analogia: A Máquina de Café

Imagina que tens uma máquina de café no escritório:

  • O Botão (Nome da Função): O botão diz "Fazer Café".
  • O Mecanismo (Corpo da Função): Dentro da máquina, há instruções complexas (moer grão, aquecer água, deitar chávena). Tu não precisas de ver isso acontecer.
  • O Ato de Carregar (Chamada): Sempre que queres café, carregas no botão. Não tens de construir a máquina do zero em cada chávena!

No código, as funções permitem-te "carregar no botão" de ações que criaste anteriormente.

5. Exemplos Práticos

Exemplo 1: Declarar e Chamar

A estrutura base indispensável.

// 1. Declarar a função
function dizerOla() {
  console.log("Olá! Bem-vindo à fábrica de código! 👋");
}

// 2. Chamar a função (executar)
dizerOla();
dizerOla(); // Podes repetir quantas vezes quiseres!

Exemplo 2: Funções com Ação Real

Agrupar várias linhas de código.

function limparConsola() {
  console.log("A limpar...");
  console.clear();
  console.log("Sistema pronto! ✨");
}

limparConsola();

Exemplo 3: O Princípio DRY

Evitar a repetição chata.

// Errado ❌ (Repetição)
console.log("--- RELATÓRIO ---");
console.log("Data: 2025");
console.log("-----------------");

// Certo ✅ (Usando Funções)
function imprimirSeparador() {
  console.log("-----------------");
}

console.log("--- RELATÓRIO ---");
imprimirSeparador();

8. Resumo do Que Aprendemos

  • 📌 **Funções** são blocos de lógica reutilizáveis.
  • 📌 Usamos a palavra reservada **function** para criá-las.
  • 📌 Uma função só funciona quando é **chamada** pelo seu nome acompanhado de `()`.
  • 📌 Ajudam a manter o código limpo, organizado e fácil de manter.

9. Desafios Práticos

Desafio 1: O Alarme

Cria uma função chamada dispararAlarme que faz um alert("PERIGO!") e usa o console.error para deixar uma mensagem vermelha na consola.

Solução:
function dispararAlarme() { alert("PERIGO!"); console.error("Alarme Ativado!"); }

Desafio 2: A Chamada Silenciosa

Se escreveres function teste() { console.log("Oi"); } mas NÃO escreveres teste();, o que vai aparecer no ecrã?

Solução: **Nada.** A função foi apenas definida (guardada na memória), mas nunca recebeu a ordem para ser executada.

Desafio 3: Ordem de Factores

Podes chamar uma função ANTES de a declarares no ficheiro? O JavaScript permite isso?

Solução: Sim! Graças a um conceito chamado **Hoisting**, o JavaScript "puxa" as declarações de funções para o topo antes de rodar o código.
