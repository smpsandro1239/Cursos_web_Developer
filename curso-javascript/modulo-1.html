  • ✅ Regras para dar nomes a variáveis (Camel Case).
  • ✅ Como o JavaScript organiza a informação na memória.

4. Teoria: Caixas Etiquetadas

Conceito: Uma variável é um pequeno espaço na memória do computador onde guardamos um valor (um nome, um número, uma cor). Damos-lhe um nome para podermos ir lá buscar esse valor sempre que precisarmos.

📦 Analogia: As Caixas das Mudanças

Imagina que estás a mudar de casa:

  • A Caixa (Variável): É o contentor onde guardas algo.
  • A Etiqueta (Nome): Escreves "Livros" na caixa. Assim, quando quiseres ler, não precisas de abrir todas as caixas.
  • O Conteúdo (Valor): São os livros propriamente ditos.
  • Fixa vs. Temporária: Se usares const, é como uma caixa selada com cola forte — o que está lá dentro não muda. Se usares let, a caixa tem uma tampa fácil de abrir — podes trocar os livros por pratos a qualquer momento!

5. Exemplos Práticos

Exemplo 1: Declarar Variáveis

Usar let (muda) e const (não muda).

const nomeDoCurso = "Aprende Web"; // Não vai mudar
let pontuacao = 0; // Vai mudar ao longo do curso

pontuacao = 10; // ✅ Ok
nomeDoCurso = "Outro Curso"; // ❌ Erro! Não podes mudar uma const

Exemplo 2: Tipos de Dados Básicos

As três cores fundamentais do código.

const nome = "Sandro";         // String (Texto entre aspas)
const idade = 25;             // Number (Números sem aspas)
const estaLogado = true;      // Boolean (Verdadeiro ou Falso)
const preco = 19.99;          // Number (Decimais usam ponto .)

Exemplo 3: Camel Case

A forma correta (profissional) de escrever nomes.

// Errado ❌
const nome_do_utilizador = "...";
const nomedoutilizador = "...";

// Certo (Camel Case) ✅
const nomeDoUtilizador = "Sandro";
const totalDeProdutosNaLoja = 50;

8. Resumo do Que Aprendemos

  • 📌 **const** é para valores que nunca mudam.
  • 📌 **let** é para valores que podem ser alterados.
  • 📌 **Strings** usam aspas (""), **Numbers** e **Booleans** não.
  • 📌 Programadores usam **camelCase** para nomes legíveis.

9. Desafios Práticos

Desafio 1: O Batizado

Quais destes nomes de variáveis são válidos em JavaScript profissional?

A) minha_idade
B) minhaIdade
C) 1idade

Solução: A opção **B** (minhaIdade) é a padrão Camel Case. A opção A funciona mas é menos comum. A opção C é **inválida** (nomes não podem começar com números).

Desafio 2: Erro de Identidade

Se escreveres const pi = 3.14; e logo a seguir pi = 4;, o que vai acontecer na consola?

Solução: Vais receber um erro de tipo: Uncaught TypeError: Assignment to constant variable. Valores constantes não podem ser reatribuídos.

Desafio 3: Tipagem

Se let valor = "10";, qual o tipo deste dado? String ou Number?

Solução: É uma **String**, porque está entre aspas. Para o computador, isso é texto e não o número dez matemático!
