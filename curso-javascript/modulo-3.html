Módulo 3: Tomar Decisões (If/Else)

2. Resumo da Aula Anterior

No Módulo 2, aprendemos a usar operadores para comparar valores (ex: idade >= 18). Agora, vamos usar essas comparações para fazer o nosso código escolher caminhos diferentes.

3. O Que Vais Aprender Hoje

  • ✅ A estrutura base: if e else.
  • ✅ Como usar o else if para múltiplas escolhas.
  • ✅ Blocos de código (chavetas {}).
  • ✅ Operador Ternário (o atalho dos profissionais).

4. Teoria: O Cruzamento do Código

Conceito: O controlo de fluxo permite que o programa execute certas instruções apenas se uma condição for verdadeira. Se a condição for falsa, o programa pode ignorar esse código ou seguir por um caminho alternativo.

🚥 Analogia: O GPS do Código

Imagina que estás a conduzir com um GPS:

  • IF (SE): "Se houver trânsito na ponte, vira à direita".
  • ELSE IF (SENÃO SE): "Senão se a estrada estiver cortada, segue em frente".
  • ELSE (SENÃO): "Se nada disso acontecer (caminho normal), atravessa a ponte".

O teu código funciona exatamente assim: ele avalia a estrada à frente e toma a decisão mais lógica!

5. Exemplos Práticos

Exemplo 1: If / Else Básico

O clássico verificador de idade.

const idade = 20;

if (idade >= 18) {
  console.log("Podes entrar na discoteca! 🕺");
} else {
  console.log("És muito novo, volta para casa. 🏠");
}

Exemplo 2: O Semáforo (Else If)

Mais do que apenas dois caminhos.

const corSemaforo = "Amarelo";

if (corSemaforo === "Verde") {
  console.log("Avança!");
} else if (corSemaforo === "Amarelo") {
  console.log("Atenção, trava!");
} else {
  console.log("Para IMEDIATAMENTE! 🛑");
}

Exemplo 3: Operador Ternário

Transformar 5 linhas em apenas 1.

const saldo = 50;

// Forma normal
// let mensagem;
// if (saldo > 0) { mensagem = "Tens dinheiro"; } else { mensagem = "Estás liso"; }

// Forma Ternária ✅
const mensagem = saldo > 0 ? "Tens dinheiro 💰" : "Estás liso 💸";
console.log(mensagem);

6. Agora é a Tua Vez!

Vamos criar um "Verificador de Notas":

  1. Cria uma variável const nota = 14; (Escala 0 a 20).
  2. Escreve um if: Se a nota for maior ou igual a 10, imprime "Aprovado!".
  3. Adiciona um else if: Se a nota for entre 8 e 9, imprime "Recurso".
  4. Adiciona um else: Para notas abaixo de 8, imprime "Reprovado".
  5. Muda o valor da nota e vê a mensagem mudar na consola.

8. Resumo do Que Aprendemos

  • 📌 **if** testa uma condição.
  • 📌 **else** é o caminho de "rejeição" da condição.
  • 📌 **else if** permite testar várias condições em cadeia.
  • 📌 O **operador ternário** é perfeito para decisões simples de sim/não.

9. Desafios Práticos

Desafio 1: O Número Secreto

Cria um código que verifica se a variável numero é par ou ímpar (Dica: Usa o operador % que aprendeste na aula anterior).

Solução:
if (numero % 2 === 0) { console.log("Par"); } else { console.log("Ímpar"); }

Desafio 2: Login de Utilizador

Tens uma variável const userRole = "admin";. Cria uma estrutura que imprima "Acesso Total" se for admin, e "Acesso Limitado" se for qualquer outra coisa.

Solução:
if (userRole === "admin") { console.log("Acesso Total"); } else { console.log("Acesso Limitado"); }

Desafio 3: Ternário Veloz

Como escreverias "Adulto" se a idade for >= 18, senão "Menor", usando apenas uma linha de código?

Solução:
const status = idade >= 18 ? "Adulto" : "Menor";
