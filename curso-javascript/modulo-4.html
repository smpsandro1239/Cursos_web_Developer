Módulo 4: A Escolha Múltipla (Switch)

2. Resumo da Aula Anterior

No Módulo 3, aprendemos a usar if e else para tomar decisões. Mas o que acontece quando temos 10 opções diferentes? Usar 10 else if torna o código muito "sujo" e difícil de ler. É aqui que o Switch nos salva!

3. O Que Vais Aprender Hoje

  • ✅ A sintaxe do comando switch.
  • ✅ Os termos case, break e default.
  • ✅ Porquê o break é obrigatório (e o que acontece se o esqueceres).
  • ✅ Organizar escolhas como dias da semana ou menus de opções.

4. Teoria: A Estação de Comboios

Conceito: O Switch avalia uma expressão e compara o resultado com vários "casos" possíveis. É uma forma mais organizada e limpa de gerir múltiplas condições que dependem da mesma variável.

🚂 Analogia: A Estação de Comboios

Imagina que o teu código é um comboio que chega a uma grande estação com 7 linhas:

  • A Variável (Bilhete): O comboio tem um bilhete que diz "Linha 4".
  • O Case (A Linha): O comboio passa pela Linha 1? Não. Linha 2? Não. Linha 3? Não. Linha 4? SIM!
  • O Break (O Batente): Mal o comboio entra na linha certa, ele deve parar. Se não houver travão (break), o comboio continua a andar e entra nas linhas 5, 6 e 7 sem autorização!
  • O Default (Linha de Emergência): Se o bilhete for para uma linha que não existe, o comboio é enviado para a linha de segurança por defeito.

5. Exemplos Práticos

Exemplo 1: Dias da Semana

O uso mais comum do switch.

const dia = 3;

switch (dia) {
  case 1: console.log("Segunda-feira"); break;
  case 2: console.log("Terça-feira"); break;
  case 3: console.log("Quarta-feira"); break; // Vai parar aqui! ✅
  default: console.log("Fim de semana ou dia inválido");
}

Exemplo 2: Menu de Comandos

Gerindo ações do utilizador.

const accao = "delete";

switch (accao) {
  case "save":
    console.log("A guardar ficheiro...");
    break;
  case "delete":
    console.log("A apagar ficheiro... 🔥");
    break;
  default:
    console.log("Ação não reconhecida.");
}

Exemplo 3: Cases Agrupados

Quando várias opções levam ao mesmo resultado.

const fruta = "Laranja";

switch (fruta) {
  case "Limão":
  case "Laranja":
  case "Toranja":
    console.log("Esta fruta é um Citrino! 🍊");
    break;
  default:
    console.log("Outro tipo de fruta.");
}

6. Agora é a Tua Vez!

Vamos criar um "Seletor de Idiomas":

  1. Cria uma variável const lang = "pt";.
  2. Cria um switch(lang).
  3. No case "pt", imprime "Bem-vindo!".
  4. No case "en", imprime "Welcome!".
  5. No case "es", imprime "Bienvenido!".
  6. Adiciona um default que imprime "Idioma não suportado".
  7. Lembra-te de colocar o break em cada caso!

8. Resumo do Que Aprendemos

  • 📌 **switch** compara uma variável com vários valores fixos.
  • 📌 **case** define cada uma das opções.
  • 📌 **break** é vital para o código não continuar a executar os próximos casos.
  • 📌 **default** é o plano B se nada coincidir.

9. Desafios Práticos

Desafio 1: O Batente em falta

Se o teu código imprimir duas coisas ao mesmo tempo num switch, qual é o erro mais provável?

Solução: Esqueceste-te de colocar o comando break; no final do caso que foi ativado primeiro.

Desafio 2: A Calculadora Simples

Como estruturarias um switch que recebe uma variável operacao (que pode ser "+", "-", "*" ou "/") para fazer uma conta entre dois números?

Solução:
switch(operacao) { case "+": res = a + b; break; case "-": res = a - b; break; ... }

Desafio 3: Default Power

É possível ter um switch sem o comando default? Isso causará um erro?

Solução: Sim, é possível e **não dá erro**. No entanto, se nenhum caso coincidir, o switch simplesmente não fará nada, o que pode ser mau para a experiência do utilizador.
