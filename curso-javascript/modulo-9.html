Módulo 9: Funções II (Dados e Resultados)

2. Resumo da Aula Anterior

No Módulo 8, aprendemos a criar funções básicas para reutilizar código. No entanto, essas funções faziam sempre exatamente a mesma coisa. Hoje, vamos aprender a enviar dados para as funções e a receber resultados de volta.

3. O Que Vais Aprender Hoje

  • ✅ O que são Parâmetros e Argumentos.
  • ✅ A palavra reservada return.
  • ✅ Funções que fazem cálculos e devolvem valores.
  • ✅ O conceito de funções como caixa-preta.

4. Teoria: Encomendas e Entregas

Conceito: As funções podem receber informações (parâmetros) para trabalhar. Depois de processarem esses dados, elas podem "devolver" um resultado para o programa principal usando o comando return.

📦 Analogia: A Pizzaria

Imagina que ligas para uma pizzaria:

  • A Encomenda (Parâmetros): Tu dizes: "Quero uma pizza de **Fiambre** e **Queijo**". Estes são os dados que envias para a função `fazerPizza`.
  • O Trabalho: O pizzaiolo recebe os ingredientes e faz a pizza. Tu não precisas de saber como o forno funciona.
  • A Entrega (Return): O estafeta chega à tua porta e entrega a **Pizza Pronta**. No JavaScript, o `return` é esse momento em que a função te entrega o produto final.

5. Exemplos Práticos

Exemplo 1: Funções com Parâmetros

Enviar dados para dentro da função.

function cumprimentar(nome) {
  console.log("Olá, " + nome + "! Bem-vindo.");
}

cumprimentar("Sandro"); // "Olá, Sandro! Bem-vindo."
cumprimentar("Maria");  // "Olá, Maria! Bem-vindo."

Exemplo 2: O Comando Return

Receber um valor de volta para guardar numa variável.

function somar(a, b) {
  return a + b;
}

const resultado = somar(10, 20);
console.log(resultado); // 30 ✅

Exemplo 3: Lógica com Return

Verificar condições e devolver respostas.

function eAdulto(idade) {
  if (idade >= 18) {
    return "Sim, é adulto";
  } else {
    return "Não, é menor";
  }
}

console.log(eAdulto(25)); // "Sim, é adulto"

Vamos criar um "Conversor de Moedas":

8. Resumo do Que Aprendemos

  • 📌 **Parâmetros** são variáveis que a função espera receber.
  • 📌 **Argumentos** são os valores reais que enviamos ao chamar a função.
  • 📌 **return** envia um valor para fora da função e encerra a sua execução.
  • 📌 O código após um `return` é ignorado pelo JavaScript.

9. Desafios Práticos

Desafio 1: Calculadora de Área

Cria uma função que recebe a base e a altura de um retângulo e devolve a sua área.

Solução:
function area(b, h) { return b * h; }

Desafio 2: O Carrinho Inteligente

Cria uma função que recebe um preco e uma quantidade. Se a quantidade for maior que 10, dá um desconto de 10% no total.

Solução:
function total(p, q) { let subtotal = p * q; if (q > 10) return subtotal * 0.9; return subtotal; }

Desafio 3: Undefined?

O que acontece se chamares uma função que NÃO tem o comando return e tentares guardar o resultado numa variável?

Solução: A variável ficará com o valor **undefined**. Todas as funções em JS devolvem `undefined` por defeito se não usares o `return` explicitamente.
