Módulo 6: Arrays (Listas)

2. Resumo da Aula Anterior

No Módulo 5, aprendemos a usar loops (for e while) para repetir tarefas. Mas repetir tarefas com uma única variável é limitado. Hoje, vamos aprender a guardar várias coisas dentro de uma única variável organizada: o Array.

3. O Que Vais Aprender Hoje

  • ✅ O que é um Array e como criá-lo.
  • ✅ Aceder a dados através do índice (e porquê começamos no zero).
  • ✅ Métodos básicos: adicionar e remover elementos.
  • ✅ Percorrer listas com loops.

4. Teoria: A Estante de Livros

Conceito: Um Array é uma lista ordenada de valores. Em vez de teres 10 variáveis diferentes para 10 alunos, tens um único "Array de Alunos" onde cada um ocupa uma posição numerada.

🛒 Analogia: A Lista de Compras

Imagina que vais ao supermercado:

  • A Lista (Array): É o papel onde escreves tudo o que precisas.
  • Os Itens (Elementos): Arroz, Massa, Leite. Cada um é um valor no teu Array.
  • A Posição (Índice): No JavaScript, o primeiro item está na posição número **0**. O segundo na **1**, e assim por diante.

Se tiveres 3 itens na lista, o último item está na posição **2**. Lembra-te: o computador sempre conta a partir do zero!

5. Exemplos Práticos

Exemplo 1: Criar e Aceder

Usar parênteses retos `[]` e índices.

const frutas = ["Maçã", "Banana", "Laranja"];

console.log(frutas[0]); // "Maçã" ✅
console.log(frutas[2]); // "Laranja"
console.log(frutas.length); // 3 (quantidade de itens)

Exemplo 2: Manipular a Lista

Adicionar e remover dados de forma dinâmica.

const compras = ["Arroz", "Pão"];

compras.push("Leite"); // Adiciona ao fim da lista
compras.pop();         // Remove o último item ("Leite")

console.log(compras); // ["Arroz", "Pão"]

Exemplo 3: O Array com o Loop FOR

A combinação mais poderosa do JavaScript.

const nomes = ["Ana", "Bruno", "Carla"];

for (let i = 0; i < nomes.length; i++) {
  console.log("Olá, " + nomes[i]);
}

O loop começa em 0 e vai até ao tamanho da lista, visitando cada nome um por um.

6. Agora é a Tua Vez!

Vamos criar a tua "Playlist":

  1. Cria um Array const playlist = ["Musica 1", "Musica 2"];.

  3. Imprime na consola apenas a segunda música da lista (lembra-te do índice!).
  4. Usa um loop for para imprimir todas as músicas da tua playlist.

8. Resumo do Que Aprendemos

  • 📌 **Arrays** guardam coleções de dados entre `[]`.
  • 📌 O primeiro elemento está sempre no **índice 0**.
  • 📌 **.length** diz-nos quantos itens existem no Array.
  • 📌 **.push()** adiciona ao final; **.pop()** remove do final.

9. Desafios Práticos

Desafio 1: O Último da Fila

Se tiveres um Array chamado cores, como acederias ao último elemento de forma dinâmica (sem saber se tem 3 ou 50 itens)?

Solução: Usando cores[cores.length - 1].

Desafio 2: Carrinho de Compras

Cria um Array com preços e usa um loop para somar o valor total de todos os itens.

Solução:
let total = 0; for(let i=0; i < precos.length; i++) { total += precos[i]; }

Desafio 3: Alteração Direta

Como mudarias o valor da primeira posição de const lista = ["Antigo"]; para "Novo"?

Solução:
lista[0] = "Novo"; (Nota: podes mudar o conteúdo de um Array mesmo que ele seja uma const!).
