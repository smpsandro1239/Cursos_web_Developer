Módulo 11: Eventos I (Interatividade)

2. Resumo da Aula Anterior

No Módulo 10, aprendemos a usar o DOM para capturar elementos do HTML. Agora que já sabemos como "segurar" o elemento, vamos aprender a fazê-lo reagir quando o utilizador toca nele.

3. O Que Vais Aprender Hoje

  • ✅ O conceito de "Escutar" (Listening) eventos.
  • ✅ O segredo do addEventListener.
  • ✅ Capturar Cliques, Movimentos do Rato e Teclado.
  • ✅ O objeto event: a caixa preta da interação.

4. Teoria: A Campainha da Porta

Conceito: Um Evento é qualquer coisa que acontece no browser iniciada pelo utilizador ou pelo sistema. Programar com eventos é dizer ao JavaScript: "Fica atento a ISTO e, quando acontecer, faz AQUILO".

🔔 Analogia: A Campainha

Imagina que estás à espera de uma encomenda:

  • O Botão (Elemento): É a campainha física lá fora.
  • O Toque (Evento): É o estafeta a carregar no botão (`click`).
  • O Ouvido (EventListener): É o teu cérebro atento ao som. Tu "adicionaste um escutador" de campainha.
  • A Ação (Função): É tu ires abrir a porta.

Se não estivesses atento (se não houvesse `addEventListener`), a campainha podia tocar mil vezes e tu nunca abririas a porta!

5. Exemplos Práticos

Exemplo 1: O Clique Clássico

EventListener: o método preferido dos profissionais.

const botao = document.getElementById("meu-botao");

botao.addEventListener("click", function() {
  alert("Clicaste no botão! 🎉");
  botao.style.backgroundColor = "green";
});

Exemplo 2: Eventos de Teclado

Saber o que o utilizador escreveu.

const input = document.querySelector("#caixa-texto");

input.addEventListener("keydown", function(event) {
  console.log("Tecla premida: " + event.key);

  if (event.key === "Enter") {
    console.log("Submeteste o texto!");
  }
});

O parâmetro `event` (ou `e`) guarda todos os pormenores da ação do utilizador.

Exemplo 3: Rato a Passear (Hover)

Detetar quando o utilizador passa o rato por cima.

const imagem = document.querySelector("img");

imagem.addEventListener("mouseenter", () => {
  imagem.style.opacity = "0.5";
});

imagem.addEventListener("mouseleave", () => {
  imagem.style.opacity = "1";
});

6. Agora é a Tua Vez!

Vamos criar um "Interruptor de Luz":

  1. No teu HTML, cria um botão com o texto "Ligar/Desligar".
  2. No JS, seleciona o botão e o document.body.
  3. Cria uma let luzAcesa = false;.
  4. Adiciona um `click` ao botão que inverte o valor da variável.
  5. Se for true, muda o fundo do body para amarelo; se for false, volta a branco.

8. Resumo do Que Aprendemos

  • 📌 Eventos são a base da Web interativa.
  • 📌 **addEventListener** recebe dois pedreiros: o tipo de evento e a função.
  • 📌 O objeto **event** permite-nos saber qual tecla foi clicada ou a posição do rato.
  • 📌 Podes ter vários escutadores no mesmo elemento para eventos diferentes.

9. Desafios Práticos

Desafio 1: O Contador Dinâmico

Cria dois botões (+ e -) e um número no ecrã. Faz com que o número aumente ou diminua ao clicar nos botões respetivos.

Solução:
btnMais.addEventListener('click', () => { num++; span.textContent = num; });

Desafio 2: Espelho de Texto

Cria um <input> e um <p>. Faz com que tudo o que o utilizador escreve no input apareça instantaneamente no parágrafo. (Dica: usa o evento `input`).

Solução:
input.addEventListener('input', (e) => { paragrafo.textContent = e.target.value; });

Desafio 3: Segredo da Tecla

Cria um código que só dispara um alert("Código Secreto!") se o utilizador premir a tecla "S" no teclado.

Solução:
window.addEventListener('keydown', (e) => { if(e.key === 's' || e.key === 'S') alert('...'); });
