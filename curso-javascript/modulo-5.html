4. Teoria: Automatizar o Trabalho Chato

Conceito: Um loop (ciclo) é uma estrutura que repete um bloco de código enquanto uma condição for verdadeira. É ideal para tarefas repetitivas, como listar 100 produtos ou contar até 1000.

♻️ Analogia: O Castigo das 100 Frases

Lembras-te dos filmes onde o aluno tem de escrever 100 vezes no quadro "Não voltarei a lançar aviões"?

  • Forma Manual: Tu escreves a frase 1. Depois a 2. Depois a 3... cansas-te e demoras o dia todo.
  • Forma Programador (Loop): Tu dizes ao robot: "Enquanto o número de frases for menor que 100, escreve a frase e soma 1 ao contador".
  • O Robot (Computador): Faz as 100 frases em menos de um segundo sem reclamar e sem se cansar!

5. Exemplos Práticos

Exemplo 1: O Loop FOR

O mestre da contagem precisa.

// (início; condição; incremento)
for (let i = 1; i <= 5; i++) {
  console.log("Número: " + i);
}

Este loop vai imprimir de 1 a 5. O i++ significa que somamos 1 ao "i" em cada volta.

Exemplo 2: O Loop WHILE

Repete enquanto não sabemos o fim exato.

let bateria = 100;

while (bateria > 0) {
  console.log("Smartphone ligado...");
  bateria = bateria - 20; // Consumindo bateria
}
console.log("Desligado.");

Exemplo 3: O Perigo do Infinito ⚠️

Nunca faças isto!

// while (true) {
//   console.log("Socorro!");
// }

Se a condição nunca for falsa, o loop nunca para. Isso gasta toda a memória e faz o browser travar.

8. Resumo do Que Aprendemos

  • 📌 **for** usa-se quando sabemos o número de voltas.
  • 📌 **while** usa-se quando a repetição depende de uma condição externa.
  • 📌 Lembra-te sempre de **incrementar** ou alterar a variável para o loop não ser infinito.
  • 📌 Loops são ideais para percorrer listas de dados (que veremos em breve!).

9. Desafios Práticos

Desafio 1: Números Pares

Como farias um loop que imprime apenas os números pares de 0 a 10?

Solução:
for (let i = 0; i <= 10; i += 2) { console.log(i); } ou usando if (i % 2 === 0) lá dentro.

Desafio 2: Soma Acumulada

Queres somar todos os números de 1 a 10. Como guardarias esse resultado?

Solução:
let soma = 0; for (let i = 1; i <= 10; i++) { soma += i; }

Desafio 3: Do While vs While

Em que situação usarias o do while em vez do while?

Solução: Sempre que precisares que a ação aconteça **pelo menos uma vez** antes de perguntar "devo continuar?". Ex: Pedir uma password ao utilizador.
