  • ✅ A hierarquia (árvore) de elementos do browser.

4. Teoria: O Site como um Objeto

Conceito: O DOM é a representação que o browser cria do teu ficheiro HTML. Ele transforma cada tag (h1, p, div) num "objeto" que o JavaScript consegue manipular. É como se o HTML fosse o corpo e o DOM fosse o painel de controlo.

🤵 Analogia: O Mordomo do Site

Imagina que o teu site é uma mansão de luxo:

  • O HTML (A Mansão): É a estrutura física com paredes e móveis.
  • O DOM (O Mordomo): É o funcionário que conhece todos os recantos. Se tu disseres "Mordomo, muda a cor do sofá da sala", ele vai lá e faz.
  • O JavaScript (As Tuas Ordens): Tu és o dono da casa. Tu dás as ordens ao Mordomo através de comandos de código.

Sem o Mordomo (DOM), tu não consegues falar com a casa!

5. Exemplos Práticos

Exemplo 1: Selecionar Elementos

Como "agarrar" o HTML pelo código.

// Pelo ID (Mais rápido)
const titulo = document.getElementById("meu-titulo");

// Por Seletor CSS (Mais flexível)
const subtitulo = document.querySelector(".descricao");

Exemplo 2: Mudar Conteúdo

Injetar novos textos sem editar o ficheiro HTML.

const link = document.getElementById("meu-link");

// Muda apenas o texto
link.textContent = "Clica aqui agora!";

// Muda o HTML lá dentro
link.innerHTML = "Novo Texto";

Exemplo 3: Alterar Estilos (CSS)

O JavaScript também sabe "pintar" o site.

const caixa = document.querySelector(".caixa-azul");

caixa.style.backgroundColor = "red";
caixa.style.borderRadius = "10px";
caixa.style.display = "none"; // Faz desaparecer!

6. Agora é a Tua Vez!

Vamos fazer uma "Mensagem Mágica":

  1. No teu HTML, cria um <h1 id="mensagem">Texto Antigo</h1>.
  2. No teu app.js, cria uma variável para agarrar esse h1.
  3. Usa o textContent para mudar o texto para "O DOM é fantástico!".
  4. Muda a cor do texto para azul (blue) usando .style.color.
  5. Muda o tamanho da fonte para 50px.

9. Desafios Práticos

Desafio 1: O Camaleão

Cria uma função que, ao ser chamada, muda a cor de fundo (background) de todo o site (document.body) para uma cor aleatória.

Solução:
document.body.style.backgroundColor = "lightgreen"; (Podes testar com nomes de cores ou hexadecimais).

Desafio 2: Contador Visual

Imagina que tens um <span id="contador">0</span>. Como farias para aumentar esse número via JavaScript?

Solução:
const s = document.getElementById("contador"); s.textContent = Number(s.textContent) + 1;

Desafio 3: QuerySelector All

Se quiseres trocar a cor de TODOS os parágrafos <p> do site de uma só vez, o querySelector normal chega para o trabalho?

Solução: Não. O querySelector comum agarra apenas o **primeiro** que encontrar. Para todos, deves usar querySelectorAll e um loop para percorrer cada parágrafo.
