Módulo 2: Operadores e Lógica

2. Resumo da Aula Anterior

No Módulo 1, aprendemos a guardar dados em caixas chamadas variáveis usando let e const. Hoje, vamos aprender a fazer operações com esses dados: somar, comparar e decidir.

3. O Que Vais Aprender Hoje

  • ✅ Operadores Aritméticos (+, -, *, /, %).
  • ✅ Operadores de Comparação (==, ===, >, <).
  • ✅ Operadores Lógicos (&&, ||, !).
  • ✅ A diferença crucial entre igualdade comum e estrita.

4. Teoria: As Engrenagens do Código

Conceito: Os operadores são símbolos que dizem ao JavaScript para realizar uma ação. Pode ser uma conta matemática simples ou uma comparação complexa para saber se uma palavra-passe está correta.

🍳 Analogia: Receita de Culinária

Imagina que estás a seguir uma receita:

  • Aritméticos (+): "Adiciona 2 ovos ao leite". Estás a somar ingredientes.
  • Comparação (>): "Verifica se a temperatura é maior que 180 graus". Estás a comparar valores.
  • Lógicos (&&): "O bolo está pronto SE o tempo acabou E o palito sair seco". Precisas que as duas coisas sejam verdade ao mesmo tempo.

5. Exemplos Práticos

Exemplo 1: Operadores Matemáticos

Muito além da soma básica.

const soma = 10 + 5;     // 15
const resto = 10 % 3;    // 1 (O que sobra da divisão)
let contador = 1;
contador++;              // Agora é 2 (Atalho para somar 1)

Exemplo 2: Comparação (O Perigo)

Usa quase sempre o triplo igual (===).

console.log(5 == "5");  // true (O JS tenta ser "simpático" e converte o tipo)
console.log(5 === "5"); // false (Estrito: Tipos diferentes, logo é falso)
console.log(10 > 2);    // true

Exemplo 3: Operadores Lógicos

Combinar condições.

const temIdade = true;
const temBilhete = false;

// && (E) - Precisa dos dois
console.log(temIdade && temBilhete); // false

// || (OU) - Basta um ser verdade
console.log(temIdade || temBilhete); // true

6. Agora é a Tua Vez!

Vamos testar a lógica na consola:

  1. Cria uma variável const precoItem = 25;.
  2. Cria uma variável const saldoConta = 50;.
  3. Escreve console.log(saldoConta >= precoItem);. O que aparece?
  4. Tenta agora: console.log(10 % 2 === 0); (Isso verifica se um número é par!).

8. Resumo do Que Aprendemos

  • 📌 **% (Módulo)** dá-nos o resto de uma divisão.
  • 📌 **===** compara valor e tipo (Usa sempre este!).
  • 📌 **&&** exige que tudo seja verdadeiro.
  • 📌 **||** exige que apenas um seja verdadeiro.

9. Desafios Práticos

Desafio 1: O Par ou Ímpar

Como verificarias se o número 7 é ímpar usando o operador de módulo?

Solução: 7 % 2 !== 0 ou 7 % 2 === 1. Se o resto da divisão por 2 for 1, o número é ímpar.

Desafio 2: Segurança no Login

Tens duas variáveis: const emailCorreto = true; e const passCorreta = false;. Qual operador usarias para garantir que o utilizador só entra se AMBAS forem verdadeiras?

Solução: O operador **&&** (E lógico). Ex: emailCorreto && passCorreta.

Desafio 3: O Mistério do Contrário

O que acontece se escreveres console.log(!true);?

Solução: Aparece `false`. O operador **!** (NÃO lógico) inverte o valor booleano.
