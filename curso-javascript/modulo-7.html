Módulo 7: Objetos (Estruturas)

2. Resumo da Aula Anterior

No Módulo 6, aprendemos que os Arrays são listas ordenadas de dados. Mas e se quisermos guardar informações mais complexas sobre uma única coisa, como o nome, idade e email de um utilizador? Para isso, usamos os Objetos.

  • ✅ Notação de Ponto (Dot Notation) vs Colchetes.

4. Teoria: A Identidade de um Objeto

Conceito: Um objeto é uma coleção de propriedades relacionadas. Em vez de ser apenas um valor, ele descreve "características" de um elemento através de etiquetas chamadas chaves.

🚗 Analogia: O Carro

Imagina um carro estacionado à tua frente:

  • O Objeto: O Carro propriamente dito.
  • As Propriedades (Chave: Valor):
    • Marca: "Ferrari"
    • Cor: "Vermelho"
    • Ano: 2024
    • Ligado: false

Qualquer coisa no mundo real pode ser imitada por um objeto no JavaScript. Um utilizador, um produto de uma loja, ou até uma personagem de um jogo!

5. Exemplos Práticos

Exemplo 1: Criar um Objeto

Usar chavetas `{}`.

const telemovel = {
  marca: "Apple",
  modelo: "iPhone 15",
  preco: 999,
  estaNovo: true
};

console.log(telemovel.marca); // "Apple" (Aceder com ponto .) ✅

Exemplo 2: Modificar e Adicionar

Os objetos são flexíveis.

const carro = { marca: "Toyota" };

carro.cor = "Cinzento"; // Adiciona uma nova propriedade
carro.marca = "Tesla";  // Altera a propriedade existente

console.log(carro); // { marca: "Tesla", cor: "Cinzento" }

Exemplo 3: Misturar Estruturas

O nível profissional: Objetos e Arrays juntos.

const curso = {
  nome: "Aprende Web",
  modulos: ["HTML", "CSS", "JS"], // Array dentro de objeto
  autor: {
    nome: "Sandro",
    pais: "Portugal"
  }
};

console.log(curso.modulos[1]); // "CSS" ✅

8. Resumo do Que Aprendemos

  • 📌 **Objetos** guardam dados complexos entre `{ }`.
  • 📌 Funcionam com o sistema de **Chave: Valor**.
  • 📌 Usamos a **Notação de Ponto** (`objeto.chave`) para ver ou mudar valores.
  • 📌 Podes ter listas dentro de objetos e objetos dentro de objetos.

9. Desafios Práticos

Desafio 1: O Produtor de Filmes

Cria um objeto chamado filme com Título, Ano e um Array de Atores. Como imprimirias o nome do primeiro ator da lista?

Solução: console.log(filme.atores[0]);

Desafio 2: A Chave Dinâmica

Se tiveres const chave = "nome"; e um objeto user, como podes aceder ao nome do utilizador usando a variável chave?

Solução: Usando colchetes: user[chave]. (A notação user.chave procuraria literalmente por uma chave chamada "chave").

Desafio 3: Existência

Como verificarias na consola se o objeto carro contém a propriedade motor?

Solução:
console.log("motor" in carro); ou console.log(carro.motor !== undefined);
