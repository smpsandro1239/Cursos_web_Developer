Módulo 0: O Cérebro do Site

2. Onde Estamos?

Até agora, aprendeste a criar o esqueleto (HTML) e a dar estilo (CSS). Mas um site profissional precisa de lógica, interatividade e "pensamento". É aí que entra o **JavaScript**.

3. O Que Vais Aprender Hoje

  • ✅ O que é o JavaScript e o seu papel na Web.
  • ✅ A "Consola" - A ferramenta secreta do programador.
  • ✅ Como ligar ficheiros JS ao teu HTML.
  • ✅ O teu primeiro comando: console.log.

4. Teoria: A Inteligência Web

Conceito: JavaScript é uma linguagem de programação que permite criar conteúdo que se move, atualiza e reage ao utilizador sem ter de recarregar a página.

💡 Analogia: A Lâmpada Inteligente

Imagina uma lâmpada em tua casa:

  • O Candeeiro (HTML): É a estrutura física onde a lâmpada está enroscada.
  • A Cor do Abajur (CSS): É o que torna a luz bonita (azul, quente, etc.).
  • O Interruptor e o Sensor (JavaScript): É a lógica que diz: "SE alguém entrar na sala, ENTÃO liga a luz".

5. Exemplos Práticos

Exemplo 1: O comando console.log

Falar com o computador através da consola.

console.log("Olá do JavaScript! 🚀");
console.log(10 + 20); // O computador vai calcular e mostrar 30

Este comando serve para mostrar informações na consola de programador (F12 > Console).

Exemplo 2: O comando alert

Criar um aviso que interrompe o utilizador.

alert("Bem-vindo ao curso de JS!");

Cuidado! O alert bloqueia tudo até que o utilizador clique em "OK". Usa-o com moderação.

Exemplo 3: Ligar o ficheiro JS

Onde colocar o código no HTML.

<body>
  <h1>Olá Mundo!</h1>

  <!-- Coloca o link para o JS SEMPRE no fim do body -->
  <script src="script.js"></script>
</body>

Colocamos no fim para o browser carregar todo o site primeiro antes de tentar executar a lógica.

6. Agora é a Tua Vez!

Vamos criar o teu primeiro "Log":

  1. Cria uma pasta chamada projeto-js.
  2. Cria o ficheiro index.html.
  3. Cria um ficheiro chamado app.js na mesma pasta.
  4. No app.js, escreve: console.log("Sistema Iniciado!");.
  5. Abre o ficheiro no browser e prime F12 para veres a magia na Consola.

9. Desafios Práticos

Desafio 1: Matemática Rápida

Usa a consola para calcular quanto é 1234 multiplicado por 5678.

Solução: Escreve na consola: console.log(1234 * 5678);
O resultado é: 7,006,652.

Desafio 2: Mensagem de Boas-vindas

Faz com que o site abra um alert que diga "Olá, eu sou o [Teu Nome]!".

Solução: alert("Olá, eu sou o Sandro!");

Desafio 3: O Mistério do F12

Se o teu código JS não estiver a funcionar, qual é a primeira coisa que deves fazer?

Solução: Abrir a consola (F12) e ver se existe algum erro a vermelho (Error log).
