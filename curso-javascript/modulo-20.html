3. O Desafio: Weather Dashboard Pro

Vais construir uma aplicação que permite ao utilizador pesquisar o clima de qualquer cidade do mundo. A aplicação deve:

  • ✅ Consumir dados de uma API real de clima.
  • ✅ Mostrar temperatura, humidade e ícone do clima.
  • ✅ **LocalStorage**: Memorizar a última cidade pesquisada para a mostrar ao abrir o site.
  • ✅ Validação de erros: Se a cidade não existir, avisar o utilizador.
  • ✅ Interface Moderna: Usar o DOM para criar um visual premium.

4. Teoria: Passo a Passo da Vitória

Um bom projeto não nasce do código, nasce da estratégia. Aqui está o roteiro sugerido:

🛠️ Roteiro de Construção

  1. A Fundação (HTML/CSS): Cria uma caixa de pesquisa, um botão e uma área vazia onde os resultados vão aparecer.
  2. A Seleção (JS): Seleciona todos os elementos no teu script.
  3. A Comunicação (Fetch): Cria a função async que chama a API (podes usar a OpenWeather ou uma API de teste).
  4. A Exibição (DOM): Pega nos dados do JSON e injeta-os no HTML usando textContent e innerHTML.
  5. A Memória (LocalStorage): Assim que a pesquisa tiver sucesso, guarda o nome da cidade.
  6. O Polimento (Error Handling): Adiciona o try...catch para o caso de a internet falhar.

5. Estrutura do Código

A Lógica Central

Exemplo de como organizar as tuas funções.

const API_KEY = "tua_chave_aqui";

async function buscarClima(cidade) {
  try {
    const url = `https://api.openweathermap.org/data/2.5/weather?q=${cidade}&units=metric&appid=${API_KEY}`;
    const res = await fetch(url);
    const dados = await res.json();

    if (dados.cod === "404") throw new Error("Cidade não encontrada");

    mostrarNoEcrã(dados);
    localStorage.setItem("ultimaCidade", cidade);

  } catch (e) {
    alert(e.message);
  }
}

6. Agora é Contigo!

Dicas para o teu sucesso:

  • Usa o event.preventDefault() no formulário de pesquisa.
  • Cria uma função separada só para atualizar o HTML (Mantém o código limpo!).
  • No início do script, verifica se existe algo no localStorage.getItem("ultimaCidade"). Se sim, chama a função de busca logo ao entrar.
  • Transforma os números da temperatura em graus Arredondados com Math.round().
