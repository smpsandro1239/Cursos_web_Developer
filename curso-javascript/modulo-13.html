Módulo 13: Timers e Intervalos (Tempo)

2. Resumo da Aula Anterior

No Módulo 12, aprendemos a controlar formulários e a travar o refresh automático da página. Hoje, vamos aprender a controlar o relógio do site: como agendar ações para o futuro ou repeti-las de segundo a segundo.

3. O Que Vais Aprender Hoje

  • ✅ A função setTimeout (executar uma vez).
  • ✅ A função setInterval (executar repetidamente).
  • ✅ Como parar o tempo com clearTimeout e clearInterval.
  • ✅ Trabalhar com milissegundos.

4. Teoria: Agendar o Futuro

Conceito: No JavaScript, nem tudo acontece instantaneamente. Muitas vezes queremos que uma mensagem de erro desapareça após 3 segundos, ou que um relógio atualize a cada segundo. Para isso, usamos funções de agendamento de tempo.

⏰ Analogia: O Despertador e o Temporizador

Imagina que estás na cozinha:

  • setTimeout (O Temporizador de Ovos): Tu marcas 5 minutos. Ele conta o tempo e, quando chega ao fim, o alarme toca **uma única vez**. A tarefa acabou.
  • setInterval (O Despertador com Soneca): Tu marcas para tocar a cada 10 minutos. Ele toca, tu desligas, e 10 minutos depois ele toca **outra vez**... e outra... e outra... até tu tirares a pilha (limpares o intervalo).

5. Exemplos Práticos

Exemplo 1: setTimeout

Ação agendada para 3 segundos depois (3000ms).

console.log("Iniciando contagem de 3 segundos...");

setTimeout(function() {
  console.log("O tempo passou! 🚀");
}, 3000);

Exemplo 2: setInterval

Executar repetidamente enquanto o site estiver aberto.

let segundos = 0;

const idRelogio = setInterval(() => {
  segundos++;
  console.log("Tempo no site: " + segundos + " segundos");
}, 1000);

Exemplo 3: Parar o Intervalo

Ninguém gosta de um relógio que não para!

// Para parar o exemplo acima:
clearInterval(idRelogio);
console.log("Relógio parado.");

Guardamos o "ID" do intervalo numa variável para podermos dizer ao JS exatamente qual tempo queremos parar.

6. Agora é a Tua Vez!

Vamos criar um "Banner Temporário":

  1. Cria uma <div id="aviso">Esta mensagem vai desaparecer!</div> no HTML.
  2. No JS, usa o setTimeout para 5 segundos.
  3. Lá dentro, muda o display da div para "none" ou apaga o texto.
  4. Bónus: Cria um botão que, ao ser clicado, usa o setInterval para mudar a cor de fundo da página aleatoriamente a cada 0.5 segundos.

8. Resumo do Que Aprendemos

  • 📌 O tempo em JavaScript é medido em **milissegundos** (1s = 1000ms).
  • 📌 **setTimeout** é para ações únicas no futuro.
  • 📌 **setInterval** é para repetições constantes.
  • 📌 Usa sempre o **clear** correspondente para evitar gasto de memória desnecessário.

9. Desafios Práticos

Desafio 1: A Bomba Relógio

Cria uma contagem decrescente que começa em 10 e vai até 0. Quando chegar a zero, mostra um alert("BOOM! 🔥") e para o contador.

Solução:
let c = 10; const id = setInterval(() => { if(c === 0){ alert('BOOM!'); clearInterval(id); } else { console.log(c); c--; } }, 1000);

Desafio 2: Redirect Simulado

Faz com que, após 10 segundos, o site mude automaticamente para modulo-14.html. (Pesquisa sobre window.location.href).

Solução:
setTimeout(() => { window.location.href = "modulo-14.html"; }, 10000);

Desafio 3: O Pisca-Pisca

Cria um texto que pisca (aparece e desaparece) a cada 800 milissegundos. Como farias para que o utilizador pudesse parar este efeito ao clicar no texto?

Solução: Criar um setInterval que alterna o visibility e usar clearInterval(id) no evento de click do elemento.
