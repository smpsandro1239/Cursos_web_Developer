Módulo 5: Tabelas Clássicas

2. Resumo da Aula Anterior

Já sabes como adicionar texto, links e imagens. O teu site já tem conteúdo rico! Agora, precisamos de aprender a organizar dados complexos de forma estruturada. É aqui que entram as tabelas.

3. O Que Vais Aprender Hoje

  • ✅ A estrutura base de uma tabela (table, tr, td).
  • ✅ Como criar cabeçalhos com th.
  • ✅ Como mesclar células (como no Excel) usando colspan e rowspan.

4. Teoria: A Folha de Cálculo

Conceito: Tabelas servem para apresentar dados tabulares (linhas e colunas), como horários, preços ou classificações.

📅 Analogia: O Excel

Pensa numa folha de Excel:

  • <table>: É o ficheiro Excel inteiro.
  • <tr> (Table Row): É uma linha horizontal (1, 2, 3...).
  • <td> (Table Data): É a célula individual onde escreves os dados (A1, B2...).
  • <th> (Table Header): É a primeira linha a negrito que diz o que é cada coluna ("Nome", "Idade").

5. Exemplos Práticos

Exemplo 1: Tabela Simples

Uma lista de alunos e notas.

<table border="1">
  <tr>
    <th>Nome</th>
    <th>Nota</th>
  </tr>
  <tr>
    <td>Ana</td>
    <td>18</td>
  </tr>
  <tr>
    <td>João</td>
    <td>15</td>
  </tr>
</table>

O atributo border="1" é antigo, mas útil para visualizar. No futuro, faremos as bordas com CSS.

Exemplo 2: Mesclando Colunas

Usar colspan para ocupar mais de uma coluna.

<table>
  <tr>
    <th colspan="2">Horário Escolar</th>
  </tr>
  <tr>
    <td>Manhã</td>
    <td>Tarde</td>
  </tr>
</table>

O título "Horário Escolar" estica-se sobre as duas colunas de baixo.

Exemplo 3: Estrutura Completa

Boas práticas com thead e tbody.

<table>
  <thead>
    <tr>
      <th>Produto</th>
      <th>Preço</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Pão</td>
      <td>1€</td>
    </tr>
  </tbody>
</table>

Separar a cabeça (head) do corpo (body) ajuda o navegador e o Google a entenderem a tabela.

6. Agora é a Tua Vez!

Vamos criar um Boletim de Notas:

  1. Cria uma <table>.
  2. Na primeira linha (tr), usa th para criar as colunas: "Disciplina" e "Classificação".
  3. Cria 3 linhas de dados com as tuas disciplinas favoritas e as notas.
  4. Adiciona uma última linha com a média.

8. Resumo do Que Aprendemos

  • 📌 Tabelas são definidas por linhas (tr), não por colunas.
  • 📌 Usa th para títulos e td para dados normais.
  • 📌 colspan estica para os lados, rowspan estica para baixo.
  • 📌 Não uses tabelas para fazer o layout do site (isso era nos anos 90)! Usa-as apenas para dados.

9. Desafios Práticos

Desafio 1: O Jogo do Galo

Consegues criar a grelha do jogo do galo (3x3) usando uma tabela?

<table border="1">
  <tr>
    <td>X</td><td>O</td><td> </td>
  </tr>
  <tr>
    <td> </td><td>X</td><td>O</td>
  </tr>
  <tr>
    <td> </td><td> </td><td>X</td>
  </tr>
</table>

Desafio 2: A Fatura

Cria uma tabela onde a última célula ("Total") ocupa duas colunas usando colspan.

<tr>
  <td>Artigo 1</td>
  <td>10€</td>
</tr>
<tr>
  <td colspan="2">Total: 10€</td>
</tr>

Desafio 3: Sem Bordas?

Por defeito, as tabelas não têm bordas. Como as adicionas sem CSS (método antigo) só para testar?

Solução: Adicionando o atributo border="1" na tag <table>. Mas lembra-te: no mundo real, usamos sempre CSS (border: 1px solid black;)!
