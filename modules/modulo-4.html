Módulo 4: Imagens e Multimédia

2. Resumo da Aula Anterior

No módulo passado, aprendeste a conectar o teu site ao mundo usando Links e a organizar informação com Listas. Agora, vamos dar cor e vida a essa estrutura!

3. O Que Vais Aprender Hoje

A web não é feita só de texto. Hoje vais aprender a:

  • ✅ Inserir imagens com a tag <img>.
  • ✅ Adicionar legendas profissionais com <figure>.
  • ✅ Incorporar áudio e vídeo nas tuas páginas.
  • ✅ Entender os formatos de imagem (JPG, PNG, SVG).

4. Teoria: A Janela para o Mundo

Conceito: Imagens enriquecem a experiência do utilizador, mas precisam de ser usadas com cuidado para não pesar no carregamento.

🎨 Analogia: A Moldura

Imagina que o teu site é uma galeria de arte:

  • <img>: É a pintura em si.
  • src (source): É a instrução para o curador saber onde ir buscar a pintura ao armazém.
  • alt (texto alternativo): É a descrição que um guia faz da pintura para alguém que não consegue vê-la (acessibilidade).
  • <figure>: É a moldura da pintura.
  • <figcaption>: É a plaquinha com o nome da obra.

5. Exemplos Práticos

Exemplo 1: Imagem Básica

A tag img não tem fechamento!

<!-- Uma imagem simples -->
<img src="gato.jpg" alt="Um gato fofo a dormir no sofá">

<!-- Com controle de tamanho -->
<img src="logo.png" alt="Logótipo da Empresa" width="200" height="50">

💡 O atributo alt é OBRIGATÓRIO para um bom HTML. Ajuda cegos e o Google.

Exemplo 2: Imagem com Legenda

Usa figure para agrupar imagem e legenda semanticamente.

<figure>
    <img src="torre-belem.jpg" alt="Torre de Belém em Lisboa">
    <figcaption>Fig.1 - A Torre de Belém, Lisboa.</figcaption>
</figure>

Isto diz ao navegador: "Este texto pertence a esta imagem".

Exemplo 3: Áudio e Vídeo

Incorporar multimédia é fácil com HTML5.

<!-- Áudio -->
<audio controls>
  <source src="musica.mp3" type="audio/mpeg">
  O teu navegador não suporta áudio.
</audio>

<!-- Vídeo -->
<video width="320" height="240" controls>
  <source src="filme.mp4" type="video/mp4">
  O teu navegador não suporta vídeo.
</video>

O atributo controls adiciona play, pause e volume automaticamente.

6. Agora é a Tua Vez!

Vamos criar uma mini-galeria de perfil:

  1. Cria uma tag <h1> com o teu nome.
  2. Adiciona uma <figure>.
  3. Dentro dela, coloca uma <img> (podes usar um link da web se não tiveres ficheiros locais) e define o alt.
  4. Usa <figcaption> para escrever "Foto de perfil".
  5. Se quiseres arriscar, adiciona um <audio> com a tua música favorita.

8. Resumo do Que Aprendemos

  • 📌 <img> é void (não fecha) e precisa de src e alt.
  • 📌 Usa <figure> e <figcaption> para legendas.
  • 📌 JPG para fotos, PNG para transparência, SVG para ícones.
  • 📌 <audio> e <video> trazem multimédia nativa.

9. Desafios Práticos

Desafio 1: O Caminho Errado

O que acontece se o link da imagem estiver errado? Como garantir que o utilizador sabe o que lá estava?

Solução: Se o src falhar, o navegador mostra o ícone de imagem quebrada e o texto do atributo alt. Por isso o alt é tão importante!

Desafio 2: A Galeria de Viagem

Cria código para mostrar 3 fotos de cidades com legendas indicando o nome da cidade.

<figure>
  <img src="paris.jpg" alt="Torre Eiffel">
  <figcaption>Paris, França</figcaption>
</figure>
<figure>
  <img src="roma.jpg" alt="Coliseu">
  <figcaption>Roma, Itália</figcaption>
</figure>

Desafio 3: O Podcast

Como colocarias um episódio de Podcast na tua página que toque automaticamente (autoplay)? (Cuidado, isto pode ser irritante!)

<audio src="podcast.mp3" controls ... ></audio>

Solução: Adicionas o atributo autoplay. Exemplo: <audio controls autoplay>.... Nota: Muitos navegadores bloqueiam autoplay com som por respeito ao utilizador.
