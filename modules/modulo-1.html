  • ✅ Para que serve o <head> e o <body>.
  • ✅ A importância do <!DOCTYPE html>.

4. Teoria: A Casa Digital

Conceito: O HTML (HyperText Markup Language) é a linguagem que define a estrutura e o significado do conteúdo na web.

🏠 Analogia: A Construção de uma Casa

Imagina que estás a construir uma casa:

  • O HTML é o betão, os tijolos e as vigas (a estrutura).
  • O <head> são as plantas da casa e as licenças (informação essencial que ninguém vê de fora).
  • O <body> são as divisões, mobília e decoração (tudo o que as visitas veem).

5. Exemplos Práticos

Exemplo 1: O Mínimo Absoluto

Todo o ficheiro HTML começa assim:

<!DOCTYPE html>
<html>
</html>

O !DOCTYPE html diz ao navegador: "Isto é um site moderno (HTML5)".

Exemplo 2: Cabeça e Corpo

A divisão principal da página:

<html>
  <head>
     <!-- Metadados aqui -->
  </head>
  <body>
     <!-- Conteúdo visível aqui -->
  </body>
</html>

Nunca mistures! Conteúdo no body, configurações no head.

Exemplo 3: A Estrutura Completa

O teu ponto de partida padrão:

<!DOCTYPE html>
<html lang="pt-PT">
  <head>
    <meta charset="UTF-8">
    <title>A Minha Página</title>
  </head>
  <body>
    <h1>Olá, Mundo!</h1>
  </body>
</html>

Adicionámos lang="pt-PT" para acessibilidade e charset="UTF-8" para aceitar acentos (ç, ã, é).

6. Agora é a Tua Vez!

Abre o teu VS Code e segue estes passos:

  1. Cria um novo ficheiro chamado index.html.
  2. Digita ! e pressiona Enter (O Emmet vai criar a estrutura base).
  3. Altera o texto dentro de <title> para "O Meu Primeiro Site".
  4. Dentro do <body>, escreve <h1>Olá Mundo!</h1>.
  5. Clica com o botão direito e escolhe "Open with Live Server".

8. Resumo do Que Aprendemos

  • 📌 HTML é a estrutura, como o esqueleto de uma casa.
  • 📌 <head> contém configurações invisíveis (metadados).
  • 📌 <body> contém tudo o que o utilizador vê.
  • 📌 UTF-8 é essencial para mostrar acentos corretamente.

9. Desafios Práticos

Desafio 1: O Título Secreto

Altera o título da aba do navegador para "Experiência Secreta".

<head>
  <title>Experiência Secreta</title>
</head>

Desafio 2: O Parágrafo Perdido

Adiciona um parágrafo (<p>) abaixo do título com o texto "Estou a aprender HTML!".

<body>
  <h1>Olá Mundo</h1>
  <p>Estou a aprender HTML!</p>
</body>

Desafio 3: A Estrutura Corrompida

O código abaixo tem um erro grave. Consegues descobrir qual é?

<html>
  <body>
    <h1>Erro!</h1>
  </body>
  <head>
    <title>Site</title>
  </head>
</html>

Solução: A ordem está errada! O <head> deve vir SEMPRE antes do <body>.
