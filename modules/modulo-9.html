Módulo 9: SEO Rápido

2. Resumo da Aula Anterior

3. O Que Vais Aprender Hoje

  • ✅ O que é o SEO (Search Engine Optimization).
  • ✅ Como configurar títulos e descrições otimizadas.
  • ✅ O poder das tags Open Graph para redes sociais.
  • ✅ Como usar Favicons e URLs Canónicas.

4. Teoria: A Montra Digital

Conceito: SEO é o conjunto de técnicas que ajuda os motores de busca (como o Google) a ler, entender e recomendar o teu site.

📢 Analogia: O Cartaz Publicitário

Imagina que tens uma loja numa avenida muito movimentada:

  • Title Tag: É o nome da tua loja no letreiro principal.
  • Meta Description: É o cartaz na porta que explica o que vendes e convence as pessoas a entrar.
  • Open Graph: É como a foto da tua loja que aparece quando alguém fala dela no jornal (ou no Facebook).
  • Favicon: É o logótipo pequeno que as pessoas reconhecem à distância.

5. Exemplos Práticos

Exemplo 1: Meta Tags de Base

O que deve estar sempre no teu <head>.

<head>
  <!-- Título (máx 60 chars) -->
  <title>Receitas de Bacalhau | O Melhor Site de Cozinha</title>

  <!-- Descrição (máx 155 chars) -->
  <meta name="description" content="Aprende a fazer as melhores receitas de bacalhau tradicionais portuguesas. Passo a passo simples, rápido e delicioso.">
</head>

Uma boa descrição aumenta a probabilidade de as pessoas clicarem no teu link no Google.

Exemplo 2: Partilha Social (Open Graph)

Controla como o teu link aparece no WhatsApp ou Facebook.

<meta property="og:title" content="Curso de HTML Gratis">
<meta property="og:description" content="Aprende Web do zero ao herói.">
<meta property="og:image" content="https://meusite.com/banner.jpg">
<meta property="og:url" content="https://meusite.com">

Sem estas tags, as redes sociais escolhem uma imagem aleatória (ou nenhuma) do teu site.

Exemplo 3: Canonical e Favicon

Evitar duplicados e dar identidade.

<!-- URL Original (evita que o Google se confunda com links parecidos) -->
<link rel="canonical" href="https://meusite.com/pagina-oficial">

<!-- Ícone da aba do browser -->
<link rel="icon" href="favicon.ico" type="image/x-icon">

O canonical é vital se tiveres versões diferentes do mesmo conteúdo.

6. Agora é a Tua Vez!

Vamos otimizar o teu "Portefólio":

  1. Define um <title> apelativo (ex: "O Teu Nome | Web Developer & Designer").
  2. Escreve uma description que resuma as tuas competências.
  3. Adiciona as tags og:title e og:description.
  4. Prepara o link para o teu favicon.

8. Resumo do Que Aprendemos

  • 📌 SEO garante que o Google te encontre.
  • 📌 O Título e a Meta Description são o teu cartão de visita nas buscas.

9. Desafios Práticos

Desafio 1: O Verificador de Comprimento

Se a tua Meta Description tiver 500 caracteres, o que acontece no Google?

Solução: O Google vai cortá-la (truncated) com reticências (...). Deves mantê-la entre 150 e 160 caracteres para que seja lida na totalidade.

Desafio 2: Partilha Mistério

Colaste um link no WhatsApp e não apareceu imagem nenhuma, apenas o link azul. O que falta no código?

Solução: Falta a tag <meta property="og:image" content="..."> com o link direto para uma imagem atraente.

Desafio 3: Favicon Moderno

Antigamente usava-se apenas ficheiros .ico. Hoje em dia, que outro formato (mais leve) é muito usado para ícones?

Solução: O formato .png ou até .svg (para ícones infinitamente escaláveis).
