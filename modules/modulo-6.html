Módulo 6: Formulários Interativos

2. Resumo da Aula Anterior

No último módulo, aprendeste a organizar dados em Tabelas. Agora, vamos aprender como permitir que o utilizador envie os seus próprios dados para o site através de Formulários.

3. O Que Vais Aprender Hoje

  • ✅ Criar a estrutura base de um formulário com <form>.
  • ✅ Usar diferentes tipos de <input> (texto, email, password).
  • ✅ Implementar <label> para acessibilidade.
  • ✅ Validar campos obrigatoriamente sem usar JavaScript.

4. Teoria: A Ficha de Inscrição

Conceito: Um formulário é a principal forma de interatividade na web. Serve para logins, registos, pesquisas e pedidos.

📄 Analogia: A Receção de um Hotel

Imagina que estás a fazer o check-in num hotel:

  • <form>: É o balcão da receção onde tudo acontece.
  • <input>: São as linhas em branco na ficha que tens de preencher.
  • <label>: É o texto ao lado da linha que diz "Nome:" ou "Data de Nascimento:".
  • type="password": É como escreveres o teu código do cofre (ninguém deve ver o que escreves).
  • button type="submit": É o ato de entregares a ficha preenchida ao rececionista.

5. Exemplos Práticos

Exemplo 1: Formulário de Contacto Simples

A base de qualquer formulário.

<form action="/enviar" method="POST">
  <label for="nome">Nome:</label>
  <input type="text" id="nome" name="usuario_nome" required>

  <label for="email">Email:</label>
  <input type="email" id="email" name="usuario_email">

  <button type="submit">Enviar Mensagem</button>
</form>

O atributo for no label deve ser igual ao id do input para estarem ligados.

Exemplo 2: Escolhas e Seleções

Radios, Checkboxes e Selects.

<!-- Escolha única -->
<p>Género:</p>
<input type="radio" name="sexo" value="m" id="masc"> <label for="masc">Masculino</label>
<input type="radio" name="sexo" value="f" id="fem"> <label for="fem">Feminino</label>

<!-- Menu Suspenso -->
<label for="pais">País:</label>
<select id="pais">
  <option value="pt">Portugal</option>
  <option value="br">Brasil</option>
</select>

Inputs do tipo radio com o mesmo name permitem apenas uma seleção no grupo.

Exemplo 3: Elementos Modernos

Aproveita o poder do HTML5.

<label>Data de Nascimento: <input type="date"></label>
<label>Volume: <input type="range" min="0" max="100"></label>
<label>Cor do Site: <input type="color"></label>
<textarea placeholder="Escreve aqui a tua mensagem..."></textarea>

O textarea é usado para blocos grandes de texto, como comentários.

6. Agora é a Tua Vez!

Vamos criar um formulário de "Subscrição de Newsletter":

  1. Cria uma tag <form>.
  2. Cria um campo de texto para o "Primeiro Nome" e usa um label.
  3. Cria um campo de email e torna-o obrigatório (required).
  4. Adiciona uma checkbox que diz "Aceito os termos e condições".
  5. Termina com um botão de "Subscrever".

8. Resumo do Que Aprendemos

  • 📌 Um formulário começa sempre com a tag <form>.
  • 📌 O atributo type define se o input é texto, email, senha, etc.
  • 📌 Usa sempre <label> para que o teu site seja acessível a todos.
  • 📌 O atributo required faz a validação automática no navegador.
  • 📌 O botão de envio deve ter type="submit".

9. Desafios Práticos

Desafio 1: O Campo Fantasma

Como criarias um campo que já vem com um texto de ajuda (ex: "exemplo@mail.com") que desaparece quando o utilizador clica?

Solução: Usando o atributo placeholder. Exemplo: <input type="email" placeholder="exemplo@mail.com">.

Desafio 2: Cria um Inquérito

Cria um código que pergunte "Qual a tua linguagem favorita?" com 3 opções de escolha única (HTML, CSS, JS).

<p>Qual a tua linguagem favorita?</p>
<input type="radio" name="fav" value="h" id="h"> <label for="h">HTML</label>
<input type="radio" name="fav" value="c" id="c"> <label for="c">CSS</label>
<input type="radio" name="fav" value="j" id="j"> <label for="j">JS</label>

Desafio 3: Segredo Absoluto

Qual é o tipo de input que esconde os caracteres trocando-os por pontos ou asteriscos?

Solução: O type="password". Exemplo: <input type="password">.
