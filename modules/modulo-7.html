Módulo 7: Semântica HTML5

2. Resumo da Aula Anterior

No módulo anterior, criámos Formulários para interagir com os utilizadores. Agora que já sabemos adicionar todo o tipo de conteúdo, precisamos de aprender a dar-lhe sentido para que o Google e os leitores de ecrã o entendam perfeitamente.

3. O Que Vais Aprender Hoje

  • ✅ Por que é que a Semântica é o "segredo" do SEO (Google).
  • ✅ As tags de estrutura: header, nav, main, footer.
  • ✅ A diferença entre article e section.
  • ✅ Como organizar um site profissionalmente.

4. Teoria: O Significado das Coisas

Conceito: Semântica é usar a tag correta para o conteúdo correto. Em vez de usarmos div (que não significa nada) para tudo, usamos tags que explicam o que está lá dentro.

📦 Analogia: As Caixas de Mudanças

Imagina que estás a fazer uma mudança de casa:

  • <div>: É uma caixa de cartão castanha sem nada escrito. Ninguém sabe o que está lá dentro sem abrir.
  • <header>: É a caixa com o rótulo "Chapéus e Casacos" (fica à entrada).
  • <main>: É a caixa principal com o rótulo "Conteúdo da Sala".
  • <nav>: É como o guia/índice que diz onde está cada caixa.
  • <footer>: É a caixa com o rótulo "Notas Finais e Contactos do Transportador".

5. Exemplos Práticos

Exemplo 1: Estrutura "Old School" vs Semântica

O Google prefere a estrutura da direita!

<!-- ERRADO (Só divs) -->
<div id="cabecalho">...</div>
<div id="conteudo">...</div>

<!-- CORRETO (Semântico) -->
<header>...</header>
<main>...</main>
<footer>...</footer>

Tags semânticas ajudam a acessibilidade e o SEO sem precisares de IDs manuais para tudo.

Exemplo 2: O Miolo do Site

Usar Article e Section corretamente.

<main>
  <article>
    <h1>Notícia: Portugal ganha o Euro!</h1>
    <p>O conteúdo desta notícia faz sentido sozinho.</p>

    <section>
      <h2>Ficha de Jogo</h2>
      <p>Isto é apenas uma parte da notícia.</p>
    </section>
  </article>
</main>

Um article é independente. Uma section é uma parte de algo maior.

Exemplo 3: Navegação e Rodapé

Onde colocar os links e os créditos.

<nav>
  <ul>
    <li><a href="/">Home</a></li>
    <li><a href="/cursos">Cursos</a></li>
  </ul>
</nav>

<footer>
  <p>© 2025 - Todos os direitos reservados.</p>
</footer>

O nav deve ser usado apenas para os links de navegação principais do site.

6. Agora é a Tua Vez!

Vamos estruturar a "Página Inicial" de um blog:

  1. Cria um <header> com um <h1> título.
  2. Dentro do header, coloca um <nav> com 2 links.
  3. Cria o <main> do teu site.
  4. Dentro do main, cria um <article> para um post de blog.
  5. Termina com um <footer> com o teu nome.

8. Resumo do Que Aprendemos

  • 📌 Semântica dá significado ao código (essencial para o Google).
  • 📌 <header>, <nav>, <main> e <footer> são a espinha dorsal.
  • 📌 <article> é para conteúdo independente (como um post).
  • 📌 <section> é para agrupar temas dentro de uma página ou artigo.
  • 📌 Evita usar <div> quando existir uma tag semântica mais específica.

9. Desafios Práticos

Desafio 1: O Detetive de Tags

Se tiveres de criar uma barra lateral com "Links Úteis" ou "Anúncios", qual é a tag semântica mais correta?

Solução: A tag <aside>. Serve para conteúdo que está relacionado com o tema principal mas que está "de lado".

Desafio 2: Receita de Cozinha

Se estiveres a escrever uma receita, usarias article para a receita toda ou section?

Solução: Usarias <article> para a receita toda (porque é um conteúdo independente) e <section> para as partes ("Ingredientes", "Modo de Preparo").

Desafio 3: Onde fica o Nav?

O <nav> pode estar dentro do <footer>?

Solução: Sim! É muito comum ter uma navegação secundária (ex: links de redes sociais ou política de privacidade) dentro do footer.
