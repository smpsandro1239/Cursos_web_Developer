Módulo 2: Textos e Títulos

2. Resumo da Aula Anterior

No módulo anterior, aprendeste a criar o esqueleto da página (`html`, `head`, `body`). Hoje vamos começar a "mobilar" a casa, adicionando conteúdo textual estruturado.

3. O Que Vais Aprender Hoje

Nesta aula, vais dominar a arte de escrever para a web. Vamos ver:

  • ✅ A hierarquia de títulos (h1 a h6).
  • ✅ Como criar parágrafos (p) e quebras de linha (br).
  • ✅ A diferença entre negrito visual e semântico.

4. Teoria: A Manchete do Jornal

Conceito: A web é lida de forma "escaneável". Ninguém lê tudo palavra por palavra; as pessoas leem os títulos para encontrar o que querem.

📰 Analogia: O Jornal Diário

Imagina a primeira página de um jornal:

  • <h1>: A Manchete Principal ("O Homem Chegou à Lua"). Só existe UMA.
  • <h2>: Os títulos das secções ("Economia", "Desporto", "Cultura").
  • <h3>: As notícias dentro de cada secção.
  • <p>: O texto da notícia em si.

5. Exemplos Práticos

Exemplo 1: Hierarquia de Títulos

Usa os números para definir níveis de importância, não o tamanho da letra.

<h1>O Meu Portfólio</h1>     <!-- Título da página -->
<h2>Sobre Mim</h2>           <!-- Secção -->
<h2>Meus Projetos</h2>       <!-- Outra Secção -->
<h3>Projeto Web</h3>         <!-- Subsecção -->

💡 O Google usa isto para entender do que se trata a tua página.

Exemplo 2: Parágrafos e Quebras

O navegador ignora "Enters" no código. Tens de usar tags.

<p>Este é o primeiro parágrafo.</p>
<p>Este é o segundo.</p>

<p>Esta linha quebra aqui...<br>
e continua na linha de baixo.</p>

Usa <br> para poemas ou moradas. Para todo o resto, usa parágrafos <p> separados.

Exemplo 3: Dar Ênfase (Negrito e Itálico)

Prefere sempre as tags com significado (semânticas).

<p>Isto é <strong>muito importante</strong>!</p>
<p>Eu <em>realmente</em> gosto de HTML.</p>

<strong> = Importante (Negrito). <em> = Ênfase (Itálico).

6. Agora é a Tua Vez!

Vamos criar uma notícia de última hora:

  1. Apaga o conteúdo do <body> do exercício anterior.
  2. Cria um <h1> com: "Descoberta Incrível!".
  3. Cria um <h2> com: "Cientistas descobrem vida em Marte".
  4. Escreve um parágrafo <p> a explicar a descoberta.
  5. Usa <strong> para destacar uma frase chocante.

8. Resumo do Que Aprendemos

  • 📌 <h1> só deve haver um por página.
  • 📌 <p> cria blocos de texto (parágrafos).
  • 📌 <br> força uma quebra de linha simples.
  • 📌 Usa <strong> para coisas importantes, não apenas para pôr negrito.

9. Desafios Práticos

Desafio 1: O Poema

Escreve quatro versos de um poema. Eles devem aparecer em linhas separadas, mas pertencer ao mesmo parágrafo.

<p>
  Rosas são vermelhas,<br>
  Violetas são azuis,<br>
  O HTML é fix,<br>
  E tu também és!
</p>

Desafio 2: Receita de Bolo

Cria uma estrutura para uma receita: Título do Bolo (H1), Ingredientes (H2) e Preparacção (H2).

<h1>Bolo de Chocolate</h1>

<h2>Ingredientes</h2>
<p>Ovos, farinha, chocolate...</p>

<h2>Preparacção</h2>
<p>Bater tudo e levar ao forno.</p>

Desafio 3: O Erro de Hierarquia

O que está errado neste código?

<h1>Meu Blog</h1>
<h4>Postagem do dia</h4>
<p>Hoje acordei feliz.</p>

Solução: Saltámos do H1 diretamente para o H4! Deveríamos ter usado H2 para o subtítulo "Postagem do dia". Nunca saltes níveis de títulos.
