Módulo 3: Listas e Links

2. Resumo da Aula Anterior

Na última aula, aprendeste a estruturar textos e títulos (H1-H6) e a "encher" a tua página com conteúdo legível. Hoje vamos aprender a conectar tudo isso.

3. O Que Vais Aprender Hoje

Nesta aula, vais transformar páginas isoladas num verdadeiro website interligado:

  • ✅ Criar listas ordenadas e não ordenadas (menus, receitas, tarefas).
  • ✅ Criar hiperligações (links) para outras páginas e sites.
  • ✅ Usar "âncoras" para saltar para partes específicas da mesma página.

4. Teoria: A Teia da Aranha

Conceito: A "Web" (teia) chama-se assim porque é feita de biliões de documentos interligados por links.

🕷️ Analogia: O Mapa do Metro

Imagina que o teu site é uma cidade:

  • As Páginas são as estações.
  • Os Links (<a>) são as linhas de metro que levam as pessoas de uma estação a outra.
  • As Listas (<ul>) são os painéis de sinalização que mostram as opções de destino de forma organizada.

5. Exemplos Práticos

Exemplo 1: Lista de Compras (Não Ordenada)

Quando a ordem não importa, usa <ul> (Unordered List).

<h3>Lista de Compras</h3>
<ul>
    <li>Leite</li>
    <li>Ovos</li>
    <li>Café</li>
</ul>

Cada item da lista deve estar dentro de um <li> (List Item).

Exemplo 2: Receita (Ordenada)

Quando a ordem importa (passos), usa <ol> (Ordered List).

<h3>Como fazer Café</h3>
<ol>
    <li>Ferver água.</li>
    <li>Moer os grãos.</li>
    <li>Filtrar.</li>
</ol>

Isto vai gerar automaticamente os números 1., 2., 3...

Exemplo 3: O Link Mágico

O elemento mais poderoso da web: a âncora.

<!-- Link para o Google (site externo) -->
<a href="https://google.com" target="_blank">Ir para o Google</a>

<!-- Link para outra página do teu site -->
<a href="contacto.html">Fale Connosco</a>

href é o destino. target="_blank" abre numa nova aba.

6. Agora é a Tua Vez!

Vamos criar um Menu de Navegação:

  1. Cria uma lista não ordenada (<ul>).
  2. Dentro dela, cria 3 itens (<li>).
  3. Dentro de cada item, coloca um link (<a>): "Início", "Sobre", "Contato".
  4. Aponta os links para "#" (um link vazio que não vai a lugar nenhum, usado para testar).

8. Resumo do Que Aprendemos

  • 📌 <ul> para listas com bolinhas (menus, itens).
  • 📌 <ol> para listas numeradas (passos, rankings).
  • 📌 <li> é o item que vive DENTRO das listas.
  • 📌 <a href="..."> cria links. O atributo href é obrigatório.

9. Desafios Práticos

Desafio 1: O Top 3

Cria uma lista ordenada com os teus 3 filmes favoritos.

<ol>
  <li>Matrix</li>
  <li>Interstellar</li>
  <li>O Padrinho</li>
</ol>

Desafio 2: Menu Falso

Cria um menu de site simples usando uma lista não ordenada e links.

<ul>
  <li><a href="#home">Home</a></li>
  <li><a href="#loja">Loja</a></li>
  <li><a href="#login">Entrar</a></li>
</ul>

Desafio 3: O Link Quebrado

O que falta neste link para ele funcionar?

<a>Clique Aqui</a>

Solução: Falta o atributo href! Sem ele, o link não sabe para onde ir. O correto seria: <a href="https://...">Clique Aqui</a>.
