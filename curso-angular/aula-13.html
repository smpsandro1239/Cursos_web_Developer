Services and Dependency Injection

Aprenda a criar código reutilizável e a gerir o estado da sua aplicação com serviços.

O que vai ser capaz de fazer?

No final desta aula, você será capaz de:

  • 🎯 Entender o que são serviços em Angular e para que servem.
  • 🎯 Criar um serviço para encapsular lógica de negócio.
  • 🎯 Usar a injeção de dependências para fornecer serviços aos componentes.
  • 🎯 Partilhar dados entre componentes de forma eficiente.

Teoria (com analogia)

O que são Serviços?

Em Angular, um serviço é uma classe com um propósito bem definido. Ele existe para partilhar dados ou lógica entre diferentes componentes. Em vez de cada componente ter a sua própria lógica para, por exemplo, ir buscar dados a um servidor, um serviço pode fazer isso e fornecer os dados a qualquer componente que precise.

💡

Analogia

Pense num restaurante. Cada cozinheiro (componente) poderia ir à despensa buscar os seus próprios ingredientes. Mas seria mais eficiente ter um "ajudante de cozinha" (serviço) responsável por ir à despensa e entregar os ingredientes a qualquer cozinheiro que os peça. O Angular faz isso através da "injeção de dependências" - ele "injeta" o serviço no componente.

Prática (Passo a Passo)

Vamos criar um serviço para gerir uma lista de tarefas:

Passo 1: Crie um Serviço

Use o Angular CLI para gerar um novo serviço.

ng generate service task

Passo 2: Defina a Lógica no Serviço

No ficheiro task.service.ts, crie um array de tarefas e métodos para as obter e adicionar.

import { Injectable } from '@angular/core';

@Injectable({ providedIn: 'root' })
export class TaskService {
  private tasks: string[] = ['Aprender Angular', 'Criar um projeto'];

  getTasks() { return this.tasks; }
  addTask(task: string) { this.tasks.push(task); }
}

Passo 3: Injete o Serviço num Componente

No seu componente, injete o serviço no construtor.

import { Component } from '@angular/core';
import { TaskService } from './task.service';

@Component({ /* ... */ })
export class TaskListComponent {
  tasks: string[];
  constructor(private taskService: TaskService) {
    this.tasks = this.taskService.getTasks();
  }
}

Teste o seu conhecimento

1. O que é Injeção de Dependências em Angular?

Explicação: A Injeção de Dependências é um padrão de design que o Angular usa para fornecer aos componentes as dependências de que precisam (como serviços), promovendo a reutilização e a modularidade.
