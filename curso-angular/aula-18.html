MÓDULO 18

Custom Directives

Expanda o vocabulário do HTML com as suas próprias diretivas de atributo.

O que vai ser capaz de fazer?

No final desta aula, você será capaz de:

  • 🎯 Entender o que são diretivas de atributo.
  • 🎯 Gerar uma nova diretiva com o Angular CLI.
  • 🎯 Manipular o elemento hospedeiro de uma diretiva com `ElementRef`.
  • 🎯 Responder a eventos do utilizador com `@HostListener`.

Teoria (com analogia)

Superpoderes para o seu HTML

Diretivas são classes que adicionam novo comportamento aos elementos no template. Já conhece algumas, como `ngIf` e `ngFor`. As diretivas de atributo, especificamente, modificam a aparência ou o comportamento de um elemento, componente ou outra diretiva.

💡

Analogia

Pense nas tags HTML como atores. Uma diretiva de atributo é como dar a um ator um adereço especial ou uma instrução. Por exemplo, pode criar uma diretiva `appHighlight` que funciona como um holofote. Onde quer que coloque essa diretiva no seu template (`

`), o "ator" (o parágrafo) fica iluminado.

Prática (Passo a Passo)

Vamos criar uma diretiva `appHighlight` que muda a cor de fundo de um elemento quando o rato passa por cima.

Passo 1: Gere a Diretiva

Use o Angular CLI.

ng generate directive highlight

Passo 2: Injete `ElementRef`

No `highlight.directive.ts`, injete o `ElementRef` para obter acesso ao elemento hospedeiro.

import { Directive, ElementRef } from '@angular/core';

@Directive({ selector: '[appHighlight]' })
export class HighlightDirective {
  constructor(private el: ElementRef) {
     this.el.nativeElement.style.backgroundColor = 'yellow';
  }
}

Passo 3: Use `@HostListener` para Reagir a Eventos

Vamos tornar a diretiva interativa.

import { Directive, ElementRef, HostListener } from '@angular/core';

@Directive({ selector: '[appHighlight]' })
export class HighlightDirective {
  constructor(private el: ElementRef) {}

  @HostListener('mouseenter') onMouseEnter() {
    this.highlight('yellow');
  }

  @HostListener('mouseleave') onMouseLeave() {
    this.highlight(null);
  }

  private highlight(color: string | null) {
    this.el.nativeElement.style.backgroundColor = color;
  }
}

Passo 4: Aplique a Diretiva

No seu template, adicione a diretiva a qualquer elemento.

<p appHighlight>Passe o rato por cima de mim!</p>

Teste o seu conhecimento

1. O que o decorador `@HostListener` faz?

Explicação: `@HostListener` declara um método que será chamado quando o elemento hospedeiro emitir um evento específico (como `mouseenter`, `mouseleave` ou `click`).

Resumo do que aprendeu

Nesta aula, aprendeu a criar as suas próprias diretivas:

  • ✅ Gerar uma diretiva com o CLI.
  • ✅ Aceder ao elemento DOM com `ElementRef`.
  • ✅ Reagir a eventos do utilizador com `@HostListener`.

As diretivas personalizadas são uma forma poderosa de criar componentes HTML reutilizáveis e encapsulados.
