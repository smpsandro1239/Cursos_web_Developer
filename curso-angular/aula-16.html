MÓDULO 16

Angular Forms

Domine a arte de recolher e validar dados do utilizador com as duas abordagens de formulários do Angular.

O que vai ser capaz de fazer?

No final desta aula, você será capaz de:

  • 🎯 Criar um formulário simples usando Template-Driven Forms.
  • 🎯 Construir um formulário robusto e escalável com Reactive Forms.
  • 🎯 Implementar validações básicas para campos de formulário.

Teoria (com analogia)

Duas Formas de Construir

Angular oferece duas abordagens para lidar com formulários: Template-Driven, que é mais simples e declarativa, e Reactive, que é mais programática e poderosa.

💡

Analogia

Template-Driven Forms são como comprar mobília pré-montada. É rápido e fácil; a maior parte da configuração já está feita para si no template (HTML). Reactive Forms são como construir a sua própria mobília a partir do zero. Dá mais trabalho e requer que defina a estrutura no seu código (TypeScript), mas oferece controlo total e flexibilidade para cenários complexos.

Prática (Passo a Passo)

Vamos criar um formulário de login com Reactive Forms.

Passo 1: Importe o Módulo

No seu `app.module.ts`, importe o `ReactiveFormsModule`.

import { ReactiveFormsModule } from '@angular/forms';

@NgModule({
  imports: [
    // ...
    ReactiveFormsModule
  ],
  // ...
})
export class AppModule { }

Passo 2: Crie o FormGroup no Componente

No seu `login.component.ts`, defina a estrutura do formulário.

import { Component } from '@angular/core';
import { FormGroup, FormControl, Validators } from '@angular/forms';

@Component({ /* ... */ })
export class LoginComponent {
  loginForm = new FormGroup({
    email: new FormControl('', [Validators.required, Validators.email]),
    password: new FormControl('', Validators.required),
  });

  onSubmit() {
    console.log(this.loginForm.value);
  }
}

Passo 3: Conecte ao Template

No seu `login.component.html`, ligue o formulário ao `FormGroup`.

<form [formGroup]="loginForm" (ngSubmit)="onSubmit()">
  <input type="email" formControlName="email">
  <input type="password" formControlName="password">
  <button type="submit" [disabled]="!loginForm.valid">Entrar</button>
</form>

Teste o seu conhecimento

1. Em Reactive Forms, onde é definida a estrutura principal do formulário?

Explicação: A principal característica dos Reactive Forms é que a estrutura, a lógica e as validações são definidas programaticamente no ficheiro TypeScript do componente.

Resumo do que aprendeu

Nesta aula, explorou os formulários em Angular:

  • ✅ Template-Driven Forms: Simples, baseados em diretivas no template.
  • ✅ Reactive Forms: Programáticos, escaláveis e mais testáveis.
  • ✅ `FormGroup` e `FormControl`: As classes centrais para construir formulários reativos.
  • ✅ Validação: Como usar validadores para garantir a qualidade dos dados.

Saber quando usar cada abordagem é fundamental para ser um desenvolvedor Angular eficaz.
