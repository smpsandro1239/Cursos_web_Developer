Testes End-to-End (E2E) com Cypress

Aprenda a automatizar testes que simulam o comportamento do utilizador final na sua aplicação Angular.

O que vai ser capaz de fazer?

No final desta aula, você será capaz de:

  • 🎯 Configurar o Cypress num projeto Angular.
  • 🎯 Escrever testes E2E para simular interações do utilizador, como cliques e preenchimento de formulários.
  • 🎯 Executar os testes e analisar os resultados para garantir a qualidade da aplicação.

Teoria (com analogia)

O que são Testes E2E?

Os testes End-to-End (E2E) verificam o fluxo completo de uma aplicação, da interface do utilizador à base de dados, simulando o comportamento de um utilizador real. O Cypress é uma ferramenta moderna que facilita a escrita e a depuração destes testes.

💡

Analogia

Pense nos testes E2E como um inspetor de qualidade que, em vez de verificar cada peça de um carro separadamente (testes unitários), entra no carro, liga-o, conduz pela cidade e testa todas as funcionalidades em conjunto — dos travões ao rádio — para garantir que a experiência do condutor é perfeita.

Prática (Passo a Passo)

Vamos escrever um teste simples para uma página de login.

Passo 1: Instalar e Configurar o Cypress

Adicione o Cypress ao seu projeto Angular.

ng add @cypress/schematic

Passo 2: Escrever o Teste

Crie um ficheiro de teste em `cypress/integration` para visitar a página de login, preencher os campos e submeter o formulário.

describe('Login Page', () => {
  it('should log in successfully', () => {
    cy.visit('/login');
    cy.get('input[name="username"]').type('testuser');
    cy.get('input[name="password"]').type('password123');
    cy.get('button[type="submit"]').click();
    cy.url().should('include', '/dashboard');
  });
});

Passo 3: Executar o Teste

Execute o Cypress para ver os testes a serem executados em tempo real num browser.

npx cypress open

Teste o seu conhecimento

1. O que o comando `cy.visit('/login')` faz num teste Cypress?

Explicação: A resposta correta é a C. O comando `cy.visit()` é usado para navegar para um URL específico antes de realizar qualquer outra interação ou asserção na página.

Resumo do que aprendeu

Nesta aula, cobrimos os seguintes pontos-chave:

  • ✅ A importância dos testes E2E para garantir a qualidade do software.
  • ✅ Como configurar o Cypress e escrever testes para simular fluxos de utilizador.
  • ✅ Como executar testes e validar o comportamento esperado da aplicação.

Com os testes E2E, você pode entregar aplicações mais confiáveis e com menos bugs.
