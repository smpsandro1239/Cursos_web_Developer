Roteamento Avançado

Leve as suas habilidades de navegação em Angular para o próximo nível.

O que vai ser capaz de fazer?

No final desta aula, você será capaz de:

  • 🎯 Criar rotas filhas (nested routes) para organizar interfaces complexas.
  • 🎯 Implementar Lazy Loading para carregar módulos apenas quando são necessários.
  • 🎯 Passar parâmetros para rotas e lê-los nos seus componentes.

Teoria (com analogia)

Navegação Inteligente

O roteador do Angular é extremamente poderoso. As técnicas avançadas permitem-lhe criar aplicações grandes e performáticas, onde diferentes partes da aplicação são carregadas sob demanda e as URLs podem conter informações dinâmicas.

💡

Analogia

Pense num grande armazém. O roteamento básico é como ter um mapa que o leva a cada secção principal. As rotas filhas são as indicações dentro de uma secção que o levam a um corredor específico. O Lazy Loading é como ter um funcionário que só vai buscar os produtos de uma secção ao armazém quando você realmente entra nessa secção, poupando tempo e esforço. E os parâmetros de rota são como pedir o produto com o número de série "123".

Prática (Passo a Passo)

Vamos configurar o Lazy Loading para um módulo.

Passo 1: Crie um Módulo com Roteamento

Use o CLI para criar um novo módulo com roteamento (ex: `admin`).

ng generate module admin --route admin --module app.module

Passo 2: Verifique o Roteamento Principal

No `app-routing.module.ts`, o CLI terá adicionado uma rota `loadChildren`.

const routes: Routes = [
  {
    path: 'admin',
    loadChildren: () => import('./admin/admin.module').then(m => m.AdminModule)
  }
];

Passo 3: Defina as Rotas no Módulo Filho

No `admin-routing.module.ts`, defina as rotas específicas para a área de administração.

const routes: Routes = [
  { path: '', component: AdminDashboardComponent }
];

Agora, o código do módulo `admin` só será carregado quando o utilizador navegar para `/admin`.

Teste o seu conhecimento

1. Qual é o principal benefício do Lazy Loading?

Explicação: O Lazy Loading divide a aplicação em pedaços mais pequenos que são carregados apenas quando necessários, o que resulta num carregamento inicial mais rápido.

  • ✅ Rotas Filhas: Para estruturar interfaces complexas.
  • ✅ Lazy Loading: Para otimizar a performance da sua aplicação.
  • ✅ Parâmetros de Rota: Para criar páginas dinâmicas.

Com estas técnicas, está pronto para construir aplicações Angular grandes e eficientes.
