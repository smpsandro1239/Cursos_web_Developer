Angular Guards

Aprenda a proteger rotas e a controlar o acesso a componentes com Guards.

Teoria (com analogia)

O que são Angular Guards?

Angular Guards são mecanismos que permitem controlar o acesso a rotas. Pode usá-los para verificar se um utilizador tem permissão para aceder a uma determinada página, por exemplo.

💡

Analogia

Pense nos Guards como seguranças de uma discoteca. Eles verificam a identidade e a idade de cada pessoa antes de a deixarem entrar. Da mesma forma, os Guards verificam certas condições antes de permitirem o acesso a uma rota.

Prática (Passo a Passo)

Vamos criar um Guard para proteger uma rota. Siga os passos abaixo:

Passo 1: Crie o Guard

Use o Angular CLI para gerar um novo Guard.

ng generate guard auth

Passo 2: Implemente a lógica

No ficheiro `auth.guard.ts`, implemente a lógica para verificar se o utilizador está autenticado.

import { Injectable } from '@angular/core';
import { CanActivate, ActivatedRouteSnapshot, RouterStateSnapshot, UrlTree, Router } from '@angular/router';
import { Observable } from 'rxjs';
import { AuthService } from './auth.service';

@Injectable({
  providedIn: 'root'
})
export class AuthGuard implements CanActivate {

  constructor(private authService: AuthService, private router: Router) {}

  canActivate(
    next: ActivatedRouteSnapshot,
    state: RouterStateSnapshot): Observable<boolean | UrlTree> | Promise<boolean | UrlTree> | boolean | UrlTree {
    if (this.authService.isLoggedIn()) {
      return true;
    } else {
      this.router.navigate(['/login']);
      return false;
    }
  }
}

Passo 3: Aplique o Guard à rota

No seu ficheiro de routing, aplique o Guard à rota que quer proteger.

{ path: 'admin', component: AdminComponent, canActivate: [AuthGuard] }
