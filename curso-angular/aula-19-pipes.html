MÓDULO 19

Pipes

Formate dados diretamente no seu HTML de forma limpa e declarativa.

O que vai ser capaz de fazer?

No final desta aula, você será capaz de:

  • 🎯 Usar os Pipes nativos do Angular, como `DatePipe`, `UpperCasePipe` e `CurrencyPipe`.
  • 🎯 Passar parâmetros para Pipes para personalizar a formatação.
  • 🎯 Encaidear (chain) múltiplos Pipes para aplicar várias transformações.

Teoria (com analogia)

Transformadores no Template

Pipes são uma forma simples de transformar dados para exibição no seu template. Eles pegam um valor de entrada e devolvem um valor formatado. São ideais para tarefas como formatar datas, converter texto para maiúsculas ou formatar números como moeda.

💡

Analogia

Pense num Pipe como um filtro de Instagram para os seus dados. Os seus dados brutos são a fotografia original. Você aplica um "filtro" (`| pipeName`) e a imagem que aparece no ecrã (no template) é a versão formatada e mais bonita, sem alterar a fotografia original.

Prática (Passo a Passo)

Vamos formatar alguns dados num componente.

Passo 1: Prepare os Dados no Componente

No seu `app.component.ts`, crie algumas propriedades.

import { Component } from '@angular/core';

@Component({ /* ... */ })
export class AppComponent {
  hoje = new Date(); // Data atual
  preco = 19.99;
  texto = 'angular é incrível';
}

Passo 2: Use Pipes no Template

No `app.component.html`, use o operador `|` para aplicar os Pipes.

<p>Data: {{ hoje | date:'dd/MM/yyyy' }}</p>
<p>Preço: {{ preco | currency:'EUR' }}</p>
<p>Texto: {{ texto | uppercase }}</p>

Passo 3: Encaidear Pipes

Pode usar múltiplos pipes. Por exemplo, vamos usar o `SlicePipe` e depois `UpperCasePipe`.

<p>Fatia de Texto: {{ texto | slice:0:7 | uppercase }}</p>
<!-- Resultado: ANGULAR -->

Teste o seu conhecimento

1. Qual é o símbolo usado para aplicar um Pipe num template?

Explicação: O símbolo `|` (pipe) é usado na sintaxe de interpolação do Angular para aplicar um Pipe a um valor.

Resumo do que aprendeu

Nesta aula, aprendeu a usar Pipes para:

  • ✅ Formatar datas, moedas e strings diretamente no HTML.
  • ✅ Passar argumentos para Pipes para personalizar a saída.
  • ✅ Combinar vários Pipes para transformações complexas.

Pipes ajudam a manter a lógica de formatação fora dos seus componentes, tornando o seu código mais limpo.
