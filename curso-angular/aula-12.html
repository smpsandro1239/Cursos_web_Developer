Aula 12 - Componentes em Angular

A base de qualquer aplicação Angular.

O que vai ser capaz de fazer?

No final desta aula, você será capaz de:

  • 🎯 Entender a estrutura e a função dos Componentes em Angular.
  • 🎯 Gerar um novo componente utilizando o Angular CLI.
  • 🎯 Entender como os componentes são declarados e utilizados.

Teoria (com analogia)

O que são Componentes?

Um Componente em Angular é uma classe TypeScript, decorada com `@Component`, que controla uma parte do ecrã (a "view"). Ele consiste no template (HTML), nos estilos (CSS) e na lógica (TypeScript).

💡

Analogia

Pense num componente como uma peça de LEGO. Cada peça é independente, tem uma forma (HTML), uma cor (CSS) e uma função específica (TypeScript). Você pode juntar várias peças de LEGO para construir algo complexo, assim como junta componentes para construir uma aplicação web completa.

Prática (Passo a Passo)

Vamos criar um componente de "Alerta".

Passo 1: Gerar o Componente

No terminal, use o Angular CLI para gerar o componente.

ng generate component alerta

Passo 2: Usar o Componente

O CLI automaticamente declara o componente no seu módulo. Para usá-lo, adicione o seu seletor (ex: ``) no HTML de outro componente.

<!-- Em app.component.html -->
<h1>Minha Aplicação</h1>
<app-alerta></app-alerta>

Teste o seu conhecimento

1. Qual comando do Angular CLI é usado para criar um novo componente?

Explicação: O comando `ng generate component` (ou o atalho `ng g c`) é a forma padrão de gerar novos componentes.

Resumo do que aprendeu

Nesta aula, cobrimos os seguintes pontos-chave:

  • ✅ Componentes são os blocos de construção das aplicações Angular.
  • ✅ Cada componente encapsula o seu HTML, CSS e TypeScript.
  • ✅ O Angular CLI simplifica a criação de componentes com `ng generate component`.
