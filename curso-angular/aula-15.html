RxJS em Angular

Explore o poder da programação reativa com RxJS para gerir fluxos de dados assíncronos.

O que vai ser capaz de fazer?

No final desta aula, você será capaz de:

  • 🎯 Entender o que são Observables e como se subscrever a eles.
  • 🎯 Usar operadores RxJS (como `map` e `filter`) para transformar dados.
  • 🎯 Integrar RxJS com o HttpClient do Angular para lidar com pedidos HTTP.

Teoria (com analogia)

O que é RxJS?

RxJS é uma biblioteca para programação reativa que usa Observables para trabalhar com fluxos de dados assíncronos. Em Angular, é fundamental para lidar com eventos, pedidos HTTP e outras operações assíncronas.

💡

Analogia

Pense num Observable como uma subscrição de um jornal. Você subscreve (`subscribe`) e, sempre que há uma nova edição (dados), ela é entregue à sua porta. Os operadores (`map`, `filter`) são como pedir ao jornaleiro para lhe entregar apenas as notícias de desporto, ou para as embrulhar de uma forma diferente.

Prática (Passo a Passo)

Vamos usar RxJS com o HttpClient para buscar dados de uma API.

Passo 1: Crie um Serviço

Crie um serviço que use o HttpClient para fazer um pedido GET.

// data.service.ts
import { Injectable } from '@angular/core';
import { HttpClient } from '@angular/common/http';
import { Observable } from 'rxjs';

@Injectable({ providedIn: 'root' })
export class DataService {
  constructor(private http: HttpClient) {}

  getUsers(): Observable<any> {
    return this.http.get('https://jsonplaceholder.typicode.com/users');
  }
}

Passo 2: Subscreva no Componente

No seu componente, injete o serviço e subscreva ao Observable.

// app.component.ts
import { Component, OnInit } from '@angular/core';
import { DataService } from './data.service';

@Component({ selector: 'app-root', template: `...` })
export class AppComponent implements OnInit {
  users: any[];

  constructor(private dataService: DataService) {}

  ngOnInit() {
    this.dataService.getUsers().subscribe(data => {
      this.users = data;
    });
  }
}

Passo 3: Use um Operador

Vamos usar o operador `map` para extrair apenas os nomes dos utilizadores.

// app.component.ts
import { map } from 'rxjs/operators';

// ...
this.dataService.getUsers().pipe(
  map(users => users.map(user => user.name))
).subscribe(names => {
  console.log(names);
});

Teste o seu conhecimento

1. Qual método é usado para "ouvir" os dados de um Observable?

Explicação: O método `.subscribe()` é usado para se subscrever a um Observable e receber os dados que ele emite.

Resumo do que aprendeu

Nesta aula, cobrimos os seguintes conceitos de RxJS:

  • ✅ Observables: Fluxos de dados que podem ser observados ao longo do tempo.
  • ✅ Subscription: O ato de se "inscrever" para receber os dados de um Observable.
  • ✅ Operators: Funções que transformam, filtram ou combinam dados de Observables.

RxJS é uma ferramenta poderosa para lidar com a assincronicidade em Angular.
