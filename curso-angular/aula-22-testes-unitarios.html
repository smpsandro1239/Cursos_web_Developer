Testes Unitários com Karma e Jasmine

Garanta a qualidade e a robustez do seu código escrevendo testes automatizados.

O que vai ser capaz de fazer?

No final desta aula, você será capaz de:

  • 🎯 Entender a importância dos testes unitários.
  • 🎯 Ler um ficheiro de teste (`.spec.ts`) gerado pelo Angular CLI.
  • 🎯 Executar os testes da sua aplicação com o comando `ng test`.
  • 🎯 Escrever um teste simples para um método de um componente.

Teoria (com analogia)

Construir com Confiança

Testes unitários são pequenos testes automatizados que verificam se uma "unidade" isolada de código (como um método ou um componente) funciona como esperado. O Angular utiliza o Karma como executor de testes (test runner) e o Jasmine como framework de testes (para escrever as asserções).

💡

Analogia

Imagine que está a construir um carro. Os testes unitários são como testar cada peça individualmente antes de a montar: testar o motor, testar os travões, testar o rádio. Se cada peça passar no seu teste, a probabilidade de o carro final funcionar corretamente é muito maior. Modificar o carro mais tarde também se torna mais seguro, porque pode voltar a correr os testes para garantir que não partiu nada.

Prática (Passo a Passo)

Vamos testar um método simples num componente.

Passo 1: O Componente

Imagine um componente com um método que soma dois números.

// calculator.component.ts
@Component({ ... })
export class CalculatorComponent {
  add(a: number, b: number): number {
    return a + b;
  }
}

Passo 2: O Ficheiro de Teste

No ficheiro `calculator.component.spec.ts`, escrevemos um teste para o método `add`.

describe('CalculatorComponent', () => {
  let component: CalculatorComponent;

  beforeEach(() => {
    component = new CalculatorComponent();
  });

  it('should add two numbers correctly', () => {
    // Act
    const result = component.add(2, 3);

    // Assert
    expect(result).toBe(5);
  });
});

Passo 3: Execute os Testes

No terminal, na pasta do seu projeto, execute o comando:

ng test

O Karma irá abrir um navegador e mostrar os resultados. O nosso teste deverá passar!

Teste o seu conhecimento

1. No Jasmine, qual função é usada para fazer uma asserção (verificar se um valor é o esperado)?

Explicação: A função `expect()` é usada em conjunto com "matchers" (como `.toBe()` ou `.toEqual()`) para verificar se os resultados do código são os esperados.

Resumo do que aprendeu

Nesta aula, demos os primeiros passos nos testes unitários em Angular:

  • ✅ A importância de testar o seu código.
  • ✅ A estrutura de um ficheiro de teste com `describe`, `it`, e `expect`.
  • ✅ O comando `ng test` para executar a suite de testes.
