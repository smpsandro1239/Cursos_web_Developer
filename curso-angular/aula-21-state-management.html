Gestão de Estado (State Management)

Centralize os dados da sua aplicação para um fluxo mais previsível.

  • 🎯 Explicar o que é "estado" (state) numa aplicação.

Teoria (com analogia)

O que é Gestão de Estado?

Gestão de Estado é o ato de gerir os dados que a sua aplicação precisa de saber para funcionar. Em aplicações complexas, vários componentes podem precisar de aceder ou modificar os mesmos dados. Uma gestão de estado eficaz centraliza esses dados (numa "store"), tornando as alterações previsíveis e fáceis de depurar.

💡

Analogia

Imagine uma cozinha de um restaurante. O "estado" é o quadro de pedidos. Se cada cozinheiro tivesse o seu próprio bloco de notas (estado local), seria o caos. Em vez disso, há um quadro central (a "store") onde todos os pedidos são afixados. Todos olham para a mesma fonte de verdade, e quando um pedido é atualizado, é atualizado para todos.

Prática (Passo a Passo)

Vamos criar uma gestão de estado simples usando um Angular Service com um `BehaviorSubject`.

Passo 1: Crie o State Service

Crie um serviço que terá o nosso estado. O `BehaviorSubject` guarda o valor atual e emite-o para novos subscritores.

// state.service.ts
import { Injectable } from '@angular/core';
import { BehaviorSubject } from 'rxjs';

@Injectable({ providedIn: 'root' })
export class StateService {
    private readonly countSource = new BehaviorSubject<number>(0);
    public readonly count$ = this.countSource.asObservable();

    increment() {
        this.countSource.next(this.countSource.value + 1);
    }
}

Passo 2: Injeta o serviço num componente

Injete o `StateService` no seu componente para poder aceder ao estado e aos métodos que o modificam.

// counter.component.ts
import { Component } from '@angular/core';
import { StateService } from './state.service';

@Component({
    selector: 'app-counter',
    template: `
        <p>Count: {{ state.count$ | async }}</p>
        <button (click)="increment()">Increment</button>
    `
})
export class CounterComponent {
    constructor(public state: StateService) {}

    increment() {
        this.state.increment();
    }
}

Passo 3: Use o componente

Qualquer instância do `app-counter` irá agora partilhar e modificar o mesmo estado centralizado no `StateService`.
